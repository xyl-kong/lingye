# 安卓平板工作区实施路线

目标：按已确认规格交付可离线编辑的安卓平板应用，以共享内容模型连接文档和白板。

1. 构建基线：使用 Android Studio 自带 JDK、现有 Android 36 SDK 与 Gradle；确认依赖解析、空应用的构建和启动。
2. 本地数据：实现带版本的页面、内容块、画布对象与附件存储，验证重启恢复、删除与恢复、保存失败处理。
3. 页面管理和文档：实现列表、搜索、标题、段落、待办、列表和图片；测试内容编辑与持久化。
4. 白板：实现独立视口变换、共享内容卡片、选择和变换、图形、连线、笔迹、橡皮及撤销重做；验证视图往返及重启后数据一致。
5. 备份和导出：实现有版本的完整备份、校验和导入为新工作区，另提供 Markdown 和 PNG 导出；测试资源和坏文件处理。
6. 平板适配：横竖屏、分屏、主题、触摸和手写笔模式；在模拟器与可用实机上检查操作、误触和性能。

每阶段先编写相应行为测试，再实现并运行验证；真实设备不可用时明确记录未验证项目。联网同步、AI 和数据库不属于此版本。
