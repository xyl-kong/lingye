# 灵页：安卓平板文档与白板开发版 0.15

界面支持中文和英文。首次启动跟随设备语言，可从左侧“设置”进入“界面语言”切换并记住选择；已有页面、文件夹、数据库字段和用户输入内容不会被自动翻译或改写。页面、文档/白板模式、概览/设置视图、当前画布工具、平移偏移和稳定 ID 对象选区会跨强停恢复。顶部仅保留文档、白板、概览和常用操作图标，切换语言不会改变主工具栏布局。

应用每次重新进入时先显示独立的“全部文档”主页，不再自动把上次文档编辑区当作首页。主页默认使用列表视图，可切换卡片网格、按最近修改或标题排序，并可从顶部新建普通文档或白板；点击具体文档后才进入编辑页，点击侧栏“全部文档”可随时返回主页。侧栏“收藏”进入同构的独立收藏主页，只显示已收藏文档；空收藏页提供点阵与悬浮卡片插画，并可按官方收藏加号行为直接创建一篇立即收藏的新文档。

“全部文档”主页支持多选、全选和批量移入回收站，操作前显示数量确认；列表与侧栏单文档行支持左滑露出打开/移动/收藏/删除或重命名/收藏/删除操作区。操作区默认位于可视边界之外，左滑时随内容一起进入，未滑动时不会覆盖标题、摘要或时间。编辑页顶栏改为文档/白板双图标、当前标题、收藏、信息和更多菜单的紧凑结构；无界画布文本框选中栏使用单一圆角浮动条，并保留四角圆形缩放手柄。

界面采用贴住屏幕上下边缘的窄侧栏、白色平直工作区和 AFFiNE 官方 `@blocksuite/icons` 图标路径。侧栏搜索、全部文档、收藏、回收站、文件夹、页面和设置统一使用 46dp 行高、15sp 标签和相同图标缩进；页面与工具选中使用轻量颜色过渡，保存状态使用轻量切换动画；系统关闭动画时会停止背景漂移。白板使用随平移和缩放同步变化的世界坐标圆点网格。

顶部“概览”显示工作区页面数、内容字符、画布对象和本地存储；下方提供内容构成、近 365 天页面编辑热力图、文件夹/模板/回收站状态以及最近页面列表。统计仅覆盖本机当前数据，不包含账户或云端用量。

提供离线页面、正文和标题、段落、一级到六级标题块、待办、项目符号、编号列表、引用、代码、分隔线和图片块。标题块按 H1–H6 分级保存，强停重开后级别和文字保持，可与其他文字块互相转换并设置整块粗体、斜体和下划线；旧版单一标题块按一级标题读取。图片、数据库和共享块不会被误转换为文本块；文本类块可安全切换类型，分隔线转换不会丢弃原文字。当前列表为单层结构，代码块保留原文但尚无语言选择和高亮。白板可平移缩放，创建笔迹、矩形、圆形、直线和独立图片；选中对象后可移动、用四角或四边中点手柄自由调整宽高、切换蓝色或黄色和删除；移动/缩放时对象工具条临时隐藏，松手后恢复。可通过多选两个图形并点击“绑定连线”创建跟随图形的连线。新绘制的连线为平滑曲线，旧连线保留直线；卡片与图形均有四周连接端口。图片保存在应用私有存储。

白板工具栏按 AFFiNE 的实际结构收纳：中央白色圆角工具条按导航、内容、绘制和更多操作分组。第一个手形/选择按钮单击即可在画布拖拽与对象选择之间切换；框选、多选、形状、文本、画笔、橡皮、连接、内容数据、更多和撤销/重做均可直接访问。内容类按钮使用按 AFFiNE 插画语言重绘的白色纸片矢量图标，线型按钮使用锁定 AFFiNE 源码对应的 `@blocksuite/icons` 路径；六个插画按钮统一 34dp 视觉尺寸、浅灰描边与单点强调色。中等宽度平板会隐藏工具文字，窄窗口会自动收起侧栏，避免顶栏和底栏被挤出边界。主工具按钮与参数条使用统一尺寸和选中样式；工具按钮与弹出菜单互斥，同一时间只保留一项选中态，打开文本、思维导图、内容或更多菜单时画布切到选择工具、菜单按钮保持为当前选项，连点关闭后仍停留在该选项而不会跳回上一个图形工具，思维导图菜单用五种布局预览图标区分结构；对象上下文工具条统一使用同一宿主，按对象边界、画布四边和软键盘上沿定位，靠近底部或右缘时自动翻转/避让；白板文本工具条中的 H1–H6、代码、引用、项目符号、编号和待办会直接创建带对应字号或前缀的画布文本对象，正文创建普通文本框，“关闭”按钮已移除，再点文本工具或选择其他工具即可收起；选中态使用灰色底，三个竖点左侧的主按钮带弹跳缩放反馈，文档/白板切换选中底色为白色，三个下拉菜单与工具栏间距约 16dp，Frame 比例浮层贴近框选按钮，右下缩放条与工具栏同高；“更多工具”只保留选择操作（多选、网格吸附）与视图（全屏画布、复位、Frame 导航），不再重复形状、连线、文本等已有一级入口。多选对象使用独立上下文栏，避免把低频操作塞进主工具条。画笔、框选、连接、形状和文本参数统一为同一样式的浮动条：相同圆角与描边、统一的 chip、颜色点与粗细控件，窄窗口可横向滑动。顶部的全屏按钮可隐藏侧栏、页头和系统栏，进入沉浸式画布；画布右上角保留退出全屏按钮。画布容器裁剪到编辑区域，卡片和工具浮层不会覆盖顶部栏。框选工具按比例创建带标题的 Frame；选中 Frame 可重命名、切换六种背景色、定位、从 Frame 导航列表跳转、复制或删除。边界完全位于 Frame 内的对象会随 Frame 一起移动，点击 Frame 内部空白会选中其中的对象，Frame 绘制在内容之下，复制 Frame 会连同成员一起复制。成员按几何包含关系实时判定，未保存父子关系，因此嵌套 Frame、删除联动和演示模式尚不支持。工具栏的链接按钮直接打开“链接已有文档”选择器，可在画布上创建指向已有页面的链接卡片：标题随目标重命名更新，目标被移入回收站或删除时显示失效状态，双击或工具条按钮打开目标，系统返回回到来源页面。思维导图工具按气泡图、向右树、向下树、组织图或大纲生成节点树；选中节点后可添加子节点或同级节点、双击修改文字、改接上级、切换布局或删除整个分支，连线随节点自动重排。图形、图片、笔迹和连线使用统一图层顺序。选择单个图形后会显示贴近对象的上下文工具条，可切换矩形/圆角矩形/圆形、填充色、边框色、实线/虚线/无边框、边框厚度、复制、图层、锁定和删除。卡片支持原位编辑、插入到文档、保存模板、复制、颜色、图层、锁定和删除；待办卡额外提供“勾选下一项”，不再弹出独立文字编辑框。文本框是独立对象，选中后显示官方顺序的块级工具条（显示在页面、Note Style、Size、Scale、连接线、锁定、更多）；编辑并选中文字时显示文本选区工具条（文本样式、对齐、粗体、斜体、下划线及更多）；双击可在原位修改，编辑中不显示“完成”按钮，点击画布外部、Esc 或 Ctrl+Enter 退出。选中图片可就地裁剪、旋转、翻转、复制、调整图层或删除；选中笔迹可就地改颜色、粗细、图层或删除。选择工具开启“多选”后可组合、取消组合、对齐和保存选区模板；锁定对象不会被误拖动。选择“移动”后拖动画布、双指缩放；选择“选择”后点击或拖动图片、图形和线条。选择“连线”后可从图形的四周端口拖到另一端口；左侧输入端口使用薄荷色，右侧输出端口使用紫色，顶部和底部为关系端口。连接线使用侧向控制点、白色描边和柔和选中光晕，端点默认显示为圆点；选中连线后可切换圆点、箭头或无端点。拖动端点时会高亮最近的目标端口。选中连线还可切换直线/曲线、光点颜色动效或删除。框选支持笔迹和连线。撤销／重做作用于当前页面编辑操作；每个页面的历史通过 `AtomicFile` 独立保存，切换页面和强停重启后仍可恢复，连续输入会在 750 ms 内合并为一次撤销步骤。Android Back 先关闭菜单、全屏和原位编辑，再退出画布，最后才离开应用。

设置页采用居中弹窗（92%×92%，只缩放弹窗本身，不改变应用页面显示比例）和左侧浅灰分类导航、右侧白色内容区，覆盖语言、外观、编辑器、键盘快捷键、偏好设置、储存和关于灵页。弹窗内容宽度小于 520dp（如 360dp 窗口或窄分屏）时自动切换为单栏：先显示分类列表，进入分区后顶部提供返回箭头，系统返回先回列表再关闭弹窗；宽屏与 640dp 分屏保持两栏。外观页提供“跟随系统 / 浅色 / 深色”主题并记住选择：深色模式覆盖侧栏、首页、文档、画布工具栏与参数条、设置、弹窗、取色器和概览，系统栏图标同步；画布内容底色仍由“编辑器 → 白板 → 画布主题”单独控制。控件统一为紧凑尺寸：分段切换为白色胶囊轨道，选中项为黑色胶囊、文字变白，未选中文字保持黑色，无箭头装饰；切换时黑色选中框在选项间平滑滑动，文字随覆盖切换颜色，首页列表/卡片视图切换同样使用滑动指示器；文档信息面板的三个分段控件也沿用黑色胶囊样式。滑块为 26dp 高、3dp 轨道与实心圆点；开关为黑白高对比的 38×22dp 胶囊并支持整行点按；工具栏和参数条按钮同步收紧。所有颜色入口共用经典色圈与 RGB/HSV 自定义取色器。配色方案行已移除，界面明暗由“界面主题”控制，其余颜色由各自入口设置。编辑器页按文档/白板分开，白板包含画布主题、按钮缩放、背景与卡片、笔记样式（带实时笔记预览；新建笔记使用全局默认，选中笔记可在其“图层与更多”菜单中单独调整阴影/圆角）、网格吸附、连线默认值、文本默认样式和画笔；桌面端专属的定价、成员、集成和云嵌入没有放入平板设置。

连接线现在可分别设置起点和终点样式，支持圆点、箭头、三角、菱形或无端点，并可在中点添加最多 200 个字符的文字标签。翻转方向会同步交换起止端口和端点标记。

设置页“数据”分类中的“备份与恢复”将页面、文件夹、共享段落、工作区模板、使用到的图片，以及文档属性/Journal/模板标记导出为 ZIP；恢复时创建新页面、图片和共享段落，并将恢复页面的引用指向新共享段落，元数据按新页面 ID 写回。备份格式为 `lingye-backup-2`，兼容读取 `lingye-backup-1`。同名模板保留工作区现有版本。图片单个限制为 20 MB；可导入 JPEG、PNG、WebP、GIF、BMP，HEIF/HEIC（Android 8+，取决于系统解码器）与 AVIF（Android 14+ 起保证，部分设备更早）；动画图片只保留首帧，SVG、TIFF、PSD 等无系统解码器的格式不支持。设置 → 储存会统计未被任何页面、模板、共享块或页面撤销历史引用的图片，并可在确认后清理。备份读取和解压总量限制为 100 MB，页面或图片条目不超过 20 MB。工作区启动加载、备份、恢复、图片读取和页面写盘在后台执行。页面与撤销历史的写入统一经过单线程写队列：主线程只复制隔离快照，编码和落盘都在写线程完成；切换页面、导出和 `onStop` 会等待队列排空后再继续，避免主线程编码较大页面，也避免较早的自动保存快照覆盖更新的重命名或结构修改。存在无法读取的数据时，备份会报错以避免静默导出不完整的数据。备份仅支持本应用格式，请自行检查导出的文件并保留其他副本。

新版可读取早期页面，但早期版本无法读取新版保存的页面。卸载应用可能删除本地数据，请先另行保存备份，不要将开发版作为唯一资料存储。

## 文档与页面管理

文档块支持上移、下移、删除和文本类块类型切换；段落、标题、待办及列表可设置整块粗体、斜体和下划线，代码和分隔线不显示无意义的文字格式按钮。每个块左侧提供 AFFiNE 手型拖拽手柄，长按后拖动可按最近的块中心重排，松手后进入页面历史并可撤销/重做；当前只支持扁平块重排，尚不能在拖动到屏幕边缘时自动滚动，也没有子块折叠。每个块尾只保留一个标准“更多”图标，类型、顺序、文字样式、共享与删除操作按类别收进二级菜单，避免逐块平铺长工具行；类型菜单再单独展开，防止底部操作被裁切。每个块左侧的 `+` 和文本块中的 `/` 斜杠菜单都可插入段落、标题、待办、项目符号、编号、引用、代码、分隔线、图片、数据库和共享块；文档底部不再保留块类型栏。斜杠菜单支持中英文关键词过滤，触控选择后会清除查询并转换当前块，尚未支持方向键/Enter 导航。文档顶部可以撤销和重做。样式仍不是对普通块选中文字范围的单独设置。左侧搜索匹配标题、正文及文字块，并受当前文件夹筛选影响。文档页头内嵌基本信息：添加/更改图标、标题、信息、工作区属性、标签、文档模式（页面/无界）、创建/更新时间、创建者、无界配色方案、页面宽度和双向链接区；页头、信息、正文、块文字和链接区使用同一内容左边界，块手柄和插入按钮位于左侧沟槽。Journal 与模板已接入页面元数据：Journal 关联日期并进入侧栏 Journals 的周历视图，可清除或改日期；模板页出现在“模板”侧栏，可新建模板、打开或用模板复制新页面；两项标记保存在本机偏好，不写入页面格式 25，也不在当前备份 ZIP 内。创建者固定显示“本机”，创建时间对旧页面是文件时间近似值，页面宽度和配色为全局设置而非每页独立属性。页面可设置 emoji 图标，侧栏、首页列表/卡片和编辑页顶栏同步显示；侧栏在“链接的文档”之外显示“反向链接”，可直接跳到来源页面。

Markdown 导入导出支持标题、正文、标题块（H1–H6 按 `##`–`######` 导出；Markdown 最多六级，H6 与 H5 共用最深一级）、待办、项目符号、编号列表、引用、代码和分隔线；带语言标记的代码围栏会正确导入为代码正文，但语言信息和高亮尚未保存。完整的导入/导出能力矩阵与限制见仓库根目录 `README.md` 的“导入与导出”一节：Markdown/HTML/快照只保留文本层级内容，完整 ZIP 备份才会保留画布、图片、模板与共享块。

段落、标题、待办、图片和数据库可通过“转为共享块”保存到本机工作区，在其他页面使用“共享块”插入引用。修改共享文字、格式、待办状态、图片或数据库会同步到所有引用；图片可以替换。选中文字后可使用“选区粗体／斜体／下划线”，原有格式按钮仍作用于整个文字块。每个共享块有独立的“共享撤销／共享重做”，历史随共享内容持久化并包含在备份中，不与页面顶部的撤销历史合并。每块最多保留 30 步，较大的历史会优先裁剪旧步骤；共享内容及历史总量有限，超过限制时保存会报错。删除页面中的引用不会删除工作区的共享内容；此功能不涉及跨设备协作。

可创建文件夹，并可为一个页面复选多个文件夹归属；删除其中一个文件夹只会移除该归属，不会清除其他归属。页面还可设置多个本机 Tags 和收藏状态，支持 Tags/收藏筛选并随备份恢复。回收站保存移入的页面并可还原至原文件夹。选中文件夹后可以重命名或删除，包含回收站页面。存在无法读取的页面时不能修改文件夹。文件夹操作使用恢复日志，但异常中断恢复尚需进一步验证。当前不支持文件夹嵌套，也没有永久删除回收站页面的入口。备份恢复会合并同名文件夹并创建新的页面，不覆盖原页面。

侧栏文件夹使用固定槽位的中心旋转箭头，并直接采用 AFFiNE 官方 `folder-icon.json` Lottie 资源实现闭合/展开文件夹动画；展开和收起不会推动文件夹图标或名称。文件夹加号菜单提供新建文档，并明确置灰尚不支持的子文件夹、导入文件和模板创建；文件夹三点菜单提供重命名、添加文档和删除，其他能力暂以禁用项展示。每个页面右侧三点菜单提供重命名、更改图标、编辑标签、查看信息、收藏、移出文件夹和移动到回收站；添加链接文档、复制和应用内新标签页已实现（标签在当前进程内有效，重启后清空）。

侧栏标题右侧使用 AFFiNE 官方 `SidebarIcon` 控制侧栏显示或隐藏；图标无可见外框，`36dp` 点击区域在行内垂直居中。侧栏隐藏后，同一图标移动到主内容左上角，首页和编辑页都可用于重新展开侧栏。编辑区原三横线按钮已移除，备份/恢复只保留在设置页。
## 手写工具

白板选择“画笔”可在普通画笔和高亮笔之间切换（⇧P 选高亮）：普通画笔提供十种颜色和 2、4、6、8、10、12 六档粗细；高亮笔以 30% 透明度绘制，提供 10、14、18、22、26、30 六档粗细和独立颜色。每条笔迹独立保存颜色与粗细，旧版笔迹沿用原默认样式。选择“橡皮”可在“整笔”和“区域”之间切换：整笔只删除碰到的笔迹；区域会删除拖拽轨迹覆盖的图形、图片、笔迹和连线，锁定对象除外，拖动时显示灰色擦除轨迹。两种模式都可以撤销，均不擦除局部像素，也不影响画布背景。笔迹可以用手指或手写笔绘制。

画笔或橡皮工具中开启“仅手写笔”，会忽略手指和鼠标在画布上的笔迹输入，手写笔输入仍可使用。需要移动画布时切换到“移动”工具。模拟器已验证模拟手指被阻止、模拟手写笔可绘制；真实平板上的手掌误触、手写笔兼容性和延迟仍需验证。当前笔迹不响应压感，橡皮按整块对象擦除，并非局部像素擦除。
## 键盘快捷键与提示

连接硬件键盘时，白板按官方工具提示支持：V 选择、H 手形、F 框选、C 连接、T 文本、P 画笔、E 橡皮、S 形状、M 思维导图、L（或 @）链接；Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做、Ctrl+A 全选、Delete/Backspace 删除选中、Esc 关闭菜单或清除选择、方向键移动选中对象（Shift 微调）、Ctrl+= / Ctrl+- / Ctrl+0 缩放和复位。文本或卡片正在编辑、菜单打开时不会拦截按键。工具按钮悬停（鼠标或手写笔）或长按会显示名称与快捷键；悬停路径尚未在模拟器验证，长按已在模拟器实测。

应用级快捷键在首页、文档和白板都可用：Ctrl+K 打开侧栏并聚焦快速搜索，Ctrl+N 新建文档，Ctrl+Shift+N 新建白板，Ctrl+, 打开设置。文档文本块获得焦点时，Ctrl+B 粗体、Ctrl+I 斜体、Ctrl+U 下划线，Ctrl+Alt+1–6 转为对应级别标题，Ctrl+Alt+0 转回正文；格式作用于当前块，转换标题后焦点保持。快捷键目前为固定映射，自定义键位尚未提供。

## 白板卡片与模板

点击卡片＋可插入笔记、待办、项目计划、会议记录或灵感预设。选择卡片后可编辑标题和正文，并保存为模板；从菜单插入模板会生成独立副本。框选对象后可选择“保存选区模板”，保存图形、图片、笔迹及选中图形之间的连线；插入时生成独立对象并重新绑定内部连线。模板图片随备份保存。跨选区的连线端点会解除绑定。卡片编辑窗口中可勾选以 ☐ 或 ☑ 开头的待办行；状态保存在正文中，支持撤销。

白板“内容与数据”按钮一次点击直接打开模板画廊，按 AFFiNE 官方分类提供 Arrows、Cheeky Piggies、Contorted Stickers、Paper、Brainstorming；画廊含搜索、分类标签和三列网格，资源取自 AFFiNE 官方 CDN，搜索框右侧保留图片/数据库入口，末尾 Cards 标签保留原笔记/待办/项目/会议/灵感卡片预设，有工作区模板时显示 Workspace 标签。官方模板目前以图片对象插入画布，不是可编辑的矢量或画布模板。


可靠性预览：拖动、缩放和擦除使用操作快照；手势进行时暂停自动保存，手势取消时回滚。损坏页面会被单独列出并保留原文件。模板可在当前页面重命名和删除，页面搜索包含卡片标题及正文。系统手掌取消事件及真机手写笔仍需进一步验证。

## 工作区模板、数据库及对象 ID

工作区模板独立保存并随备份导出；旧页面模板仍可从原页面插入。数据库支持名称、状态、可添加或删除的文本、多行、数字、复选和日期字段、筛选以及表格、看板、只读列表和月历视图；可按名称、状态或自定义字段升序和降序显示，数字字段按数值排序，空值排在末尾。当前视图、排序字段、排序方向和日历字段随数据库保存；排序只影响显示，不改写记录的手动顺序。手动顺序可通过上下按钮调整。字段支持重命名；目前不支持拖拽排序或日历中直接编辑。图形、图片、连线和笔迹均有持久化 ID，图形边框、圆角、文字色和锁定状态，以及卡片种类、文本框字号和对齐方式随页面保存；笔迹支持框选、移动、缩放和删除；选择工具提供网格吸附及边缘对齐。当前页面格式为 25。格式 21 增加多文件夹、Tags 和收藏元数据；格式 22 为连接线增加独立起点标记和可编辑文字；格式 23 增加页面 emoji 图标；格式 24 为每个图形/笔记增加独立阴影样式，选中笔记可在“图层与更多”菜单中单独调整阴影和圆角；格式 25 为每个图形追加字体族/样式/字重，并为文本对象保存字符级粗体、斜体和下划线选区。笔记卡片支持完整背景色板、画布行级待办勾选，以及插入文档时保留标题/段落/待办/列表/引用/代码围栏等 block 类型。无界画布不再显示页面摘要卡片；画布上的每张笔记/卡片都是可独立创建、选择和删除的对象，页面标题和正文仍在文档模式与文档列表中管理。文档模式不再显示底部块类型栏，插入段落/标题/待办/列表/引用/代码/分隔线/图片/数据库/共享块统一通过块左侧 `+` 或 `/` 斜杠菜单完成。打开旧页面时自动迁移为 25，旧版应用不能读取新版保存的页面，测试前先备份。迁移、回滚和格式 24 数据备份见 `docs/affine-audit/PAGE_FORMAT_25.md`。
