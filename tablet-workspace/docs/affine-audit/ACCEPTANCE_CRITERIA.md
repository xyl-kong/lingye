# AFFiNE 功能对齐验收规则

## 1. 状态定义

| 状态 | 判定条件 |
|---|---|
| VERIFIED | 当前构建有可复现证据；主流程、关键子流程和失败路径满足该条验收；没有未解决的阻塞缺陷 |
| PARTIAL | 有真实实现，但至少一个验收条件未满足，或只覆盖部分对象/平台/边界 |
| MISSING | 源码、清单、测试和 UI 都没有该能力的实现证据 |
| BROKEN | 有可识别入口或模型，但当前构建实际操作失败或产生错误状态 |
| UNVERIFIED | 证据不足，无法确认完整行为；不能算完成 |
| NOT_APPLICABLE | 经用户和产品范围双重确认不属于本项目，且记录原因；本审计默认不使用 |

不允许：

- 只因为按钮存在而标 `VERIFIED`。
- 只因为函数名称存在而标已实现。
- 空 `onClick`、占位文案、Mock 数据被视为功能。
- 单元模型测试替代真实 Android 输入验收。
- 模拟器通过替代真机手写笔验收。
- `PARTIAL` + `UNVERIFIED` 被算作完成。

## 2. 证据门槛

### 2.1 纯数据功能

示例：codec、排序、校验、迁移、备份路径拒绝。

- 必须：单元测试 + 具名 fixture/输入。
- 若涉及 UI 写入或用户可见恢复，再增加一次端到端验证。

### 2.2 UI 交互

示例：菜单、对象选择、原位编辑、返回键。

- 必须：当前 APK 实际交互 + 截图或 UI 树。
- 导航/状态类功能还必须有 instrumentation test 或明确手工复现步骤。

### 2.3 持久化功能

- 必须：修改 → 退出/强停 → 重启 → 再读取。
- 备份/恢复还必须有文件哈希或内容比对。

### 2.4 画布功能

- 必须：视觉状态、命中状态和数据往返三者一致。
- 多对象、缩放、旋转、锁定和取消至少各覆盖一个边界。

### 2.5 Android 输入

- 必须：真实设备或明确批准的模拟器输入，记录设备、OS、输入法和笔型号。
- 压感/掌托不得用单元测试代替。

### 2.6 同步/协作

- 必须：多客户端、断网、重连、冲突和权限组合。
- 单个 mock API 返回 200 不能标 `VERIFIED`。

### 2.7 AI

- 必须：明确上下文范围、请求内容、目标服务、失败/取消、撤销和隐私告知。
- 不得把静态 UI 或固定回复标为 AI 功能完成。

## 3. 通用验收

### A. 数据和迁移

- 旧格式页面只读、自动迁移或显式报错必须有定义。
- 每次 schema 变更必须有：
  - 新格式编码；
  - 旧格式读取；
  - 未知版本拒绝；
  - 损坏样本；
  - 往返测试；
  - 备份恢复测试。
- 不得静默覆盖不兼容文件。

### B. 保存与恢复

- 同一页面写入必须串行或有明确合并规则。
- 手势中暂停/取消保存策略必须可回滚。
- 页面编码不得阻塞高优先级输入线程；阈值由基准确认。
- `onStop`、切页、备份前 flush 都必须有成功/失败反馈。

### C. 错误处理

- 单一页面损坏不能隐藏其他页面。
- 单一数据库记录异常不能使整个查询崩溃。
- 图片/模板/共享块缺失必须指出对象和页面。
- 恢复失败不得留下半套页面/图片引用。

### D. 布局

至少覆盖：

- 800×1280 dp 竖屏；
- 1280×800 dp 横屏；
- 600 dp 分屏；
- 折叠屏展开/折叠；
- 100%、150%、200% 字体缩放；
- 中文、英文；
- 系统深色模式（实现后）。

没有重叠、裁切、横向溢出；主要操作可达；菜单不被键盘遮挡。

### E. 可访问性

- 关键图标按钮有名称、角色和启用/选中状态。
- 触摸目标不小于平台建议值。
- TalkBack 可完成：新建页面、切换文档/白板、搜索、选择对象、删除、导出。
- 颜色不是唯一状态提示。

### F. 性能

在主参考设备上：

- 普通输入不出现持续掉帧。
- 95% 帧不慢于 32 ms；P99 有记录和解释。
- 大画布目标必须先建立基准，再按产品性能预算确定。
- 1,000 对象和 5,000 对象不得崩溃；是否达交互帧率由阶段目标决定。

### G. 可靠性

- 原子写入中断测试至少覆盖：写入前、写入中、替换前、替换后。
- 文件夹事务至少覆盖：部分页面已写、目录已写、重启回放。
- 备份恢复至少覆盖：缺图、重复名、同名文件夹、同名模板、坏 ZIP、取消。

## 4. 模块专项验收

### 4.1 工作区

- 多文件夹：同一文档可出现在多个文件夹；移除一个不删除文档。
- Tags：增加/移除/筛选/搜索/备份恢复。
- Collections：成员顺序稳定；删除 Collection 不删页面。
- Favorites：状态跨重启；不改变页面更新时间。
- Trash：软删、恢复、永久删除各有确认；引用策略明确。
- 搜索：标题、正文、块、Tags、关联标题均可搜；错误单元格隔离。
- 模板：预览、分类、重命名、插入、删除、备份恢复。

### 4.2 文档

- 行内格式：选区、光标状态、撤销、复制粘贴、emoji/IME 边界。
- 列表：嵌套、折叠、Enter、Tab、Backspace、删除子块。
- Slash Menu：键盘和触控都能操作，点击空白关闭。
- 块拖拽：手柄、落点、嵌套、撤销和取消。
- 文档静态表格：增删行列、合并/拆分（如纳入范围）、粘贴。
- 图片：替换、说明、尺寸、失败占位、备份。
- 引用：目标重命名、目标删除、循环引用和反向链接。

### 4.3 无界画布

- 选择：单击、多选、框选、组、Frame、锁定、旋转后的边界。
- 对象工具：按对象类型可证明集合不同；低频动作收纳。
- 连接线：起止标记独立；输入/输出端口；曲线/折线/直线；标签；翻转。
- 手写：笔迹保存、擦除、撤销、压力、掌托、放大后线宽。
- 缩放：0.25–4.0；Fit；实时视图裁剪；对象在边界处不消失。
- 模板：图片/笔迹/连线/组/Frame 复制后 ID 独立。

### 4.4 数据库

- 字段：验证、格式化、排序、筛选、导入导出都遵循类型。
- 视图：配置持久化；刷新后不丢；空值/非法值有定义。
- Board：任意状态列拖拽；空列；取消；键盘替代。
- Calendar：跨月；同日多记录；直接编辑；时区/夏令时。
- Relation：失效目标不崩溃；可检视和清理。
- 大数据：分页/虚拟化和搜索性能达标。

### 4.5 Android

- Back 顺序符合第 1 节，不到最后不退出。
- 进程死亡、旋转、分屏、折叠屏后恢复页面/模式/工具/选区。
- Gboard、Samsung Keyboard、搜狗至少各验证中文组合和删除。
- 手写笔设备至少 3 类；记录延迟、丢点、掌托。
- 全屏进入/退出、刘海/挖孔/手势导航条无遮挡。

## 5. 验收记录格式

每个任务结束必须在 `FEATURE_MATRIX.csv` 和变更说明中记录：

- Feature ID。
- 当前状态。
- 当前 commit。
- APK 版本/页面格式。
- 设备与 OS。
- 输入法/手写笔。
- 复现步骤。
- 截图/录屏/UI 树路径。
- 自动测试名称。
- 未覆盖边界。

## 6. 完成声明规则

只有同时满足以下条件才可声明一个功能完成：

1. 矩阵状态为 `VERIFIED`。
2. 证据可追溯到当前构建。
3. 相关回归测试全部通过。
4. 未覆盖风险已经写入 `UNVERIFIED_ITEMS.md`。

只有全部约定范围内条目均为 `VERIFIED` 或经批准为 `NOT_APPLICABLE`，才能声明“约定范围内与 AFFiNE 对齐”。不得使用“完全对齐 AFFiNE”描述当前状态。
