# 华为风格白色取色板（2026-11-02）

用户要求：把原“自定义颜色”弹窗（图 1）替换为华为官方“天生绘画”的取色板（图 2），缺失部分自行补充；整体与图 2 类似，唯一区别是背景为纯白色。

## 1. 参考结构（图 2）

- 顶部：标题“颜色”，右上角两枚颜色预览块。
- 标签栏：色盘 / 色环 / 滑块 / 色卡，胶囊形选中态。
- 主区域：大面积 HSV 取色面板与圆形取色指示器。
- H / S / V 三条渐变滑块，右侧显示角度或百分比。
- 历史色彩：一排已使用颜色。
- 新生：3 行柔和色卡。
- 底部：Hex 颜色输入；取消 / 使用。
- 图 2 为深色背景；本实现按用户要求改为纯白背景。

## 3. 交互细节

- 色盘：圆盘角度映射色相，半径映射饱和度；下方 V 滑块控制明度。
- 色环：外圈色相环，拖动/点击改变色相；中心圆显示当前颜色；下方 S/V 滑块。
- 滑块：拖动 HSV 面板或三条滑块即时更新颜色、顶部预览与 Hex。
- 历史：默认颜色仅用于展示；选中后点“使用”才写入历史。
- 新生：固定 3 行柔和色卡，点击立即更新颜色。
- 颜色序列：在 Hex 输入框中输入合法值立即取色；非法值红框提示并保持颜色不变。
- “使用”会自动把当前颜色加入历史色卡（替代原“保存到自定义色卡”开关）。

## 5. 限制

1. **吸管未接入**：图 2 左下角的吸管需要系统级截图与取样，本次未实现；其余结构已补齐。
2. 色盘/色环为自绘 HSV 控件，不是华为的逐像素原始实现；视觉与交互近似。
3. 历史色卡上限 12；使用颜色会自动加入历史，没有单独的“保存到自定义色卡”开关。
4. 8 位十六进制忽略 alpha；颜色不透明。
5. 弹窗为模态：打开时画布只响应双指缩放，其他点击被遮罩拦截；取消/使用/返回关闭后恢复。此前“只能缩放”即由该模态遮罩造成，不是应用卡死。
6. 透明色卡返回 `0x00000000`；在需要不透明颜色的场景（如部分文字颜色）会显示为不可见，是否使用由用户决定。
