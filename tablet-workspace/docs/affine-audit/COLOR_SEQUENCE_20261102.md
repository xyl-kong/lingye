# 自定义颜色序列直接取色（2026-11-02）

用户澄清：不是增加“导入/搜索”两个按钮，而是允许在自定义颜色弹窗里输入颜色序列，直接取色。

> 后续 T46 已将弹窗重做为华为风格白色取色板，颜色序列输入保留在底部 Hex 字段；本文件记录解析规则，界面以 `COLOR_PICKER_HUAWEI_20261102.md` 为准。

## 1. 支持的颜色序列

| 输入 | 示例 | 结果 |
|---|---|---|
| 6 位十六进制 | `#893F3F`、`893F3F` | RGB 137,63,63 |
| 3 位十六进制 | `#abc` | RGB 170,187,204 |
| 8 位十六进制 | `#80EF7076` | 忽略 alpha，取 RGB EF7076 |
| RGB 三元组 | `137,63,63`、`137 63 63`、`rgb(137,63,63)` | RGB 137,63,63 |
| 自定义色卡序号 | `1`、`2`… | 对应“自定义色卡”中的第 N 个颜色 |

- 输入合法时立即更新当前颜色、RGB/HSV 滑块和圆形预览。
- 输入非法时边框变红并显示提示；颜色保持不变。
- 输入框为单行、等宽字体，按 Done 收起键盘。

## 2. 界面与行为

- 在颜色预览与“RGB”折叠区之间新增“颜色序列”行。
- 没有新增“导入”“搜索”按钮。
- 占位提示：`#893F3F / 137,63,63 / 1`。
- 下方提示：“输入颜色序列后立即取色；数字对应自定义色卡顺序”。
- 自定义颜色弹窗仍是模态弹窗：弹窗打开时画布只响应双指缩放，其他点击被遮罩拦截，这是正常模态行为；点“取消”“使用”或系统返回即可关闭并恢复画布点击。

## 3. 实现

- `ColorPicker.kt`：
  - 新增纯函数 `parseColorSequence(input, palette)`：解析 hex、RGB、rgb() 与色卡序号。
  - `ColorEditorDialog` 增加 `sequenceInput`、`sequenceError` 状态和输入框；输入变化时即时解析并更新 `color`。
  - 自定义色卡序号读取 `CustomColorStore.colors` 的当前顺序。
- 没有修改颜色存储格式与页面格式。

## 6. 限制

1. 8 位十六进制只取后三位 RGB，alpha 被忽略；颜色本身不透明。
2. 色卡序号只能在有已保存自定义色卡时使用（最多 12 个）。
3. 输入框不记忆上次输入，关闭弹窗后清空。
4. 目前仅自定义颜色弹窗提供该输入；经典色板与工具栏色板仍按色块选择。
