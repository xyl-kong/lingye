# 文档界面与无界画布界面职责审计（2026-11-01）

范围：审计“文档/无界画布”的界面职责与工具栏归属。2026-11-01 已按方案 A 完成文档块插入改造；页面格式不变。  
证据等级：**SRC** = 本地 AFFiNE 源码/本应用源码；**PRIOR** = 用户提供的官方截图（未直接访问官网）；**UNVERIFIED** = 缺少源码或官方 Android 证据。

## 1. 结论

1. 图 1 中绿色箭头指向的两个图标是**文档/无界画布模式切换**，与官方图 2 左上角的两个模式图标语义一致；它们不是问题所在，不应删除。
2. 真正不清楚的是文档模式内容底部的**常驻块类型栏**：`段落 / 标题 / 待办 / 图片 / 数据库 / 共享块 / 更多块`。官方文档界面没有这条常驻栏；官方通过块左侧的块手柄/加号和 `/` 斜杠菜单插入内容。
3. 当前实现把“插入块”做成了文档界面的常驻底栏，视觉上又和无界画布的底部对象工具栏相似，导致：
   - 用户不知道它是“插入内容”还是“格式/对象工具”；
   - 它与 `/` 斜杠菜单重复；
   - 它长期占用文档底部空间，且只有它保留图片/数据库/共享块入口，直接删除会造成功能不可达。
4. 因此不能只改颜色或文案；应把“文档块插入”迁移到块级入口（块左侧 `+` 或斜杠菜单），把底部固定区域留给无界画布对象工具。推荐方案 A 已在 2026-11-01 实施，见第 5、6 节。

## 3. 当前应用对照

### 3.1 头部（基本一致）

**SRC**：`MainActivity.kt` 文档/白板共用顶栏（`Workspace` 顶栏区域）：

- 当前：模式图标（文档/白板）、页面标题、收藏、信息、更多。
- 官方：模式图标、模式切换、标题、收藏、信息、更多、展示/分享。
- 差异：当前模式图标没有官方移动端的文字标签/分段控件；分享/展示等桌面项不适用。**不是本轮的主要问题。**

### 3.2 文档内容底部（已按方案 A 改造）

**SRC**：`MainActivity.kt` `BlocksEditor` 的 header/items/footer：

- 文档底部已没有七项块类型栏；正文后只保留双向链接区。
- 每个块左侧有 `+` 插入菜单和拖拽手柄；空文档显示“+ 输入文字或 /”。
- `/` 斜杠菜单覆盖 11 类块，包含图片、数据库、共享块。
- 信息面板与双向链接区内嵌在文档正文中，不再只存在于独立弹窗或侧栏；详见 `DOC_INFO_PANEL.md`。
- 页头、信息、正文、块文字和链接区共享 72dp 内容列；`+`/手柄占用左侧沟槽。

改造前的问题（历史记录）：常驻底栏与 `/` 重复、占用底部空间、与无界画布底栏相似，并导致图片/数据库/共享块只能从底栏进入。

### 3.3 无界画布底部（应保留）

**SRC**：`CanvasEditor` 底部工具栏：

- 选择/手形、Frame、连接线、链接、文本、画笔/橡皮、形状、内容、更多、撤销/重做；
- 对象选中后显示对象工具条；
- 页面摘要卡片已移除，不属于本次问题。

这条工具栏是**无界画布专属**，文档模式不应出现。

## 4. 职责边界（建议作为后续实现约束）

| 区域 | 文档模式 | 无界画布模式 |
|---|---|---|
| 顶部模式切换 | 有，文档/无界画布 | 有，同一控件 |
| 页面标题/收藏/信息/更多 | 有 | 有 |
| 内容区 | 标题、正文块、块手柄、斜杠菜单 | 无限画布、对象、对象工具条 |
| 底部常驻工具栏 | **不应有块类型栏** | 有对象工具栏 |
| 插入块 | 块左侧 `+`/斜杠菜单 | 画布内容菜单/文本工具，不使用文档块栏 |
| 文本格式 | 选区浮动格式栏 | 选中文本对象后的对象工具条/编辑态选区栏 |
| 缩放/Frame 导航/演示 | 无 | 有 |
| 信息/双向链接 | 官方文档页内区块；当前已在文档正文内实现信息面板与双向链接区 | 不适用 |

## 5. 改造选项

### 方案 A（已实施，接近官方）

1. 已移除文档底部的七项块类型栏。
2. 每个块左侧新增 `+` 插入入口，打开可滚动的块类型菜单。
3. `/` 斜杠菜单扩展为 11 类：段落/标题/待办/项目符号/编号/引用/代码/分隔线 + 图片/数据库/共享块。
4. 文档底部只保留正文内容；无块时显示单个“+ 输入文字或 /”占位入口。
5. 无界画布底栏保持原样，页面摘要卡片不回归。

实施结果：文档模式不再有常驻类型栏；`+` 菜单与斜杠菜单都可到达图片/数据库/共享块；数据库插入已在模拟器验证，共享块打开选择对话框。  
**SRC**：`MainActivity.kt` `BlocksEditor`、`BlockInsertMenu`、`SharedContentEditor`；`SlashCommands.kt`；`LocalDatabase.kt` `addDatabaseAfter`。

### 方案 B（改动较小）

把七项块栏收成一个悬浮的 `+ 插入` 按钮（固定在文档右下角或块列表末尾），点击打开同一组菜单。文档不再出现一排类型按钮，但仍保留一个插入入口。

优点：实现快、功能不丢失；缺点：仍不是官方的块手柄方式，视觉上仍有一个文档专用浮钮。

### 方案 C（不推荐）

保留现有底栏，只加标题/说明或折叠。它仍然占据底部、与画布工具栏相似，不能解决职责混淆。

## 6. 验收结果（方案 A）

- 文档模式没有常驻 `段落/标题/...` 底栏；底栏已从 `BlocksEditor` footer 移除。
- 空文档显示单个“+ 输入文字或 /”入口，点击创建首个段落。
- 每个块左侧 `+` 打开可滚动菜单；菜单可到达段落/标题/待办/列表/引用/代码/分隔线/图片/数据库/共享块。
- `/` 斜杠菜单扩展为 11 类，并修复了菜单高度裁掉后三类的问题；可滚动到图片/数据库/共享块。
- 已在模拟器插入数据库块；图片入口打开现有 picker；共享块打开选择对话框（无共享块时给出空态）。
- 无界画布底部工具栏与对象工具条未改动；页面摘要卡片未回归。
- 1000 blocks 仍使用 LazyColumn；块删除/索引边界补了防崩溃处理，289 项测试通过。

## 7. 限制

- 官方 BlockSuite `block-hub` 源码未在本机读取，具体左侧加号布局标注为 UNVERIFIED；当前实现采用“每个块左侧加号”的近似方案。
- 文档信息面板已内嵌正文；Journal/模板/添加属性仍为静态占位，创建者固定“本机”，页面宽度和配色为全局设置，不是每页独立属性。
- 图片选择路径只验证入口和现有 picker 回调，未在模拟器中重新导入实际图片。
- 共享块选择对话框已实现，但当前测试环境未选中具体共享块做插入往返验证。
- 新增块后不自动聚焦新块；需要用户点击输入。
