## 3. UI 保留与整改边界

保留：

- 黑白灰主色、`LingyeColors` token、现有 Surface/描边/圆角。
- 现有 `SegmentedChoice`、`SettingsDropdown`、开关、滑杆、`SettingsHelp`。
- 文档/白板双标签；不照搬官方单页滚动和蓝色控件。
- 现有设置页左侧导航与弹窗宽度。

本轮整改：

- 文档页按官方改为“常规 → 页面”，并把新建文档相关项前置。
- 预设模式改为下拉，字号/字体顺序改为官方顺序。
- 白板主题改为“无界”分组和下拉，补充“自动”选项。
- 8 处配色改为 `CollapsibleColorSetting`：标题、说明、当前颜色、展开箭头；展开后仍用原色板。
- 文本、图形、框架、连线、笔分组名称向官方靠拢。

## 4. 技术保护与影响

- 不新增依赖；折叠状态用 `remember { mutableStateOf(false) }`，只影响展示，不写入配置。
- 颜色选择仍调用原 `ColorChoiceRow` 与 `onSettingsChange`，保存、恢复、实际应用路径不变。
- 文档分组调整只移动 Composable 调用，不改 `WorkspaceSettings` 字段。
- 预设模式从分段改为 `SettingsDropdown`，仍写 `defaultPageMode`。
- 白板主题新增 `auto` 选项，使用现有 `CANVAS_THEMES` 与渲染逻辑。
- 页面级“指定主题”、图形/连线/思维导图默认值不在本轮强行加入，避免改页面格式或引入假控件。

## 5. 验收标准

1. 文档页显示“常规”和“页面”两组；常规顺序为字体样式、字号、预设模式、日期标题、添加图标、代码行号。
2. 预设模式是下拉；切换后新建页面按所选模式。
3. 字号、字体、日期格式、页面宽度、显示开关仍能保存并在重启后恢复。
4. 白板“无界”分组有默认配色下拉，浅/深/自动均能改变画布显示。
5. 8 处配色默认收起，只显示名称、当前颜色圆点和颜色名；展开显示完整色板。
6. 展开后选择颜色立即生效；收起再展开不重置；不产生重叠或越界。
7. 其他设置页（外观、快捷键、偏好、储存）不受影响。
8. 单元测试、构建、模拟器截图与重启回归通过；未验证项单独标注。

### 6.5 文本框样式闪退修复

- 现象：在白板选中文本框，打开“文本框样式”面板，点击“胶片”等阴影按钮后应用闪退。
- 系统 crash buffer 栈：`java.lang.IllegalArgumentException: 笔记阴影样式无效`，来源 `Page.kt` 的 `Page.validate()`。
- 根因：面板提供 6 种阴影（无/盒状/贴纸/纸张/悬浮/胶片），渲染器也已支持 6 种，但页面模型校验只允许前 3 种。点击后把 `paper/float/film` 写入 `Shape.shadowStyle`，下一次指针事件触发校验即抛异常。
- 修复：把 `SHADOW_STYLES` 扩展为 `none/box/sticker/paper/float/film`，校验与解码共用；保留面板六个按钮。不是删除按钮，而是补齐模型支持。
- 回归：模拟器逐个点击六个阴影按钮，应用进程保持运行，无 `FATAL EXCEPTION`；新增 `PageNoteStyleTest.allTextViewShadowStylesRoundTrip` 覆盖六种值编码/解码。
- 测试：448 项 JVM 测试通过，0 失败。

### 6.7 画布工具条选中态不跟随

- 现象：文本框“填充颜色/阴影”点了新选项，模型已经变化，但面板选中框仍停在旧选项；其他对象工具条也存在同类风险。
- 根因：`Page.shapes` 等是普通 `MutableList`，修改不会触发 Compose 快照订阅；画布只用 `geometryRevision` 通知重组。`CanvasObjectToolbarHost` 的参数包含 revision，但各工具条函数只接收同一个 `Page`/索引，Compose 会跳过它们，面板继续读旧快照。
- 修复：给全部对象工具条（卡片、图形、连线、页面链接、思维节点、Frame、图片、笔迹、文本框、文字格式）标注 `@NonSkippableComposable`，宿主每次 revision 变化时强制它们重新执行并读取当前 `Page` 数据；工具条内部的展开菜单状态仍由 `remember(index)` 保持，不会被重置。
- 验证：文本框样式面板选择绿色填充后选中环跟随绿色；再选择“贴纸”阴影后选中环从“胶片”移到“贴纸”，面板不关闭、不闪退。
- 测试：454 项 JVM 测试通过，0 失败。
- Release APK：3,456,827 字节，SHA-256 `FFCFF699FF65C132B65DDC35BC9D773E5E96C8F528B153C98DA32B649D568132`。

### 6.8 文字工具条禁用/无效入口

- 现象：文字工具参数条中的“链接”“附件”长期灰显；文字样式菜单中的项目符号、编号、待办、引用、公式灰显；文字对象更多菜单中的 Frame 区域、分组区域、复制为图片、转为链接文档灰显。
- 根因：这些按钮是早期照官方布局铺设的占位项，部分能力在别处已经存在但没有接到当前入口，部分能力根本没有数据模型。
- 修复：
  - “链接”接到现有“链接已有文档”选择器，选择后创建链接卡片。
  - “附件”接到现有图片插入流程。

### 6.11 无界画布点击不灵敏

- 原因一：Frame 的命中原先只接受标题条和边框带，正文空白直接穿透，所以必须精确点在细边框上才能选中。

  - 移除 `detectTapGestures` 的 `onDoubleTap` 参数，改为在 `onTap` 内按时间与距离手动识别双击；第一次单击立即选中，第二次才触发编辑/打开链接。
