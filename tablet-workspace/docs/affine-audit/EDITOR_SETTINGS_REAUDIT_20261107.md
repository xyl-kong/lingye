- 官方线上产品：`https://app.affine.pro` Demo Workspace，访问日期 2026-11-07。

## 3. UI 保留与整改边界

保留：

- 黑白灰主色、`LingyeColors` token、现有 Surface/描边/圆角。
- 现有 `SegmentedChoice`、`SettingsDropdown`、开关、滑杆、`SettingsHelp`。
- 文档/白板双标签；不照搬官方单页滚动和蓝色控件。
- 现有设置页左侧导航与弹窗宽度。

本轮整改：

- 文档页按官方改为“常规 → 页面”，并把新建文档相关项前置。
- 预设模式改为下拉，字号/字体顺序改为官方顺序。
- 白板主题改为“无界”分组和下拉，补充“自动”选项。
- 8 处配色改为 `CollapsibleColorSetting`：标题、说明、当前颜色、展开箭头；展开后仍用原色板。
- 文本、图形、框架、连线、笔分组名称向官方靠拢。

## 4. 技术保护与影响

- 不新增依赖；折叠状态用 `remember { mutableStateOf(false) }`，只影响展示，不写入配置。
- 颜色选择仍调用原 `ColorChoiceRow` 与 `onSettingsChange`，保存、恢复、实际应用路径不变。
- 文档分组调整只移动 Composable 调用，不改 `WorkspaceSettings` 字段。
- 预设模式从分段改为 `SettingsDropdown`，仍写 `defaultPageMode`。
- 白板主题新增 `auto` 选项，使用现有 `CANVAS_THEMES` 与渲染逻辑。
- 页面级“指定主题”、图形/连线/思维导图默认值不在本轮强行加入，避免改页面格式或引入假控件。

## 5. 验收标准

1. 文档页显示“常规”和“页面”两组；常规顺序为字体样式、字号、预设模式、日期标题、添加图标、代码行号。
2. 预设模式是下拉；切换后新建页面按所选模式。
3. 字号、字体、日期格式、页面宽度、显示开关仍能保存并在重启后恢复。
4. 白板“无界”分组有默认配色下拉，浅/深/自动均能改变画布显示。
5. 8 处配色默认收起，只显示名称、当前颜色圆点和颜色名；展开显示完整色板。
6. 展开后选择颜色立即生效；收起再展开不重置；不产生重叠或越界。
7. 其他设置页（外观、快捷键、偏好、储存）不受影响。
8. 单元测试、构建、模拟器截图与重启回归通过；未验证项单独标注。

## 6. 本轮实施结果（2026-11-07）

### 6.1 结构整改

- 文档页改为“常规 → 页面”两组，顺序：字体样式、字号、创建文档的预设模式、用当前日期自动命名、显示添加图标、代码块行号；页面组：默认文档页面宽度、显示文档信息、显示双向链接。
- 预设模式由分段控件改为 `SettingsDropdown`，选项仍为文档/白板，写入原 `defaultPageMode`。
- 白板页“画布主题”改为“无界”，配色改为 `SettingsDropdown`，新增“自动”选项；`auto` 使用现有 `CANVAS_THEMES` 与 `LingyeColors.dark` 渲染逻辑。
- 白板分组改为“无界 → 背景与卡片 → 笔记 → 文本 → 图形 → 框架 → 网格与吸附 → 连线 → 笔”，文本提前到图形之前，Frame 从背景组拆出单独成组。
- 设置弹窗右上角关闭按钮移入固定的 48dp 顶栏，内容滚动区从顶栏下方开始，避免滚动时控件钻到关闭按钮下方。

### 6.2 配色收纳

- 新增 `CollapsibleColorSetting`，复用 `ColorChoiceRow` 与 `SettingsHelp`。
- 覆盖 8 处：画布背景、新卡片颜色、笔记背景、文本颜色、图形填充、Frame 背景、连线颜色、画笔颜色。
- 收起态显示：标题、说明、帮助、当前颜色圆点、颜色名称、展开箭头。
- 展开态显示原色板；再收起再展开不重置；实际颜色写入原 `WorkspaceSettings` 字段。
- 展开/收起使用 `AnimatedVisibility`（纵向展开 + 淡入），不新增依赖。

### 6.3 模拟器验证

- 文档页：常规/页面分组顺序正确；“创建文档的预设模式”显示为下拉；字体四段无截断；开关和滑杆无重叠。
- 白板页：8 处配色默认收起；收起态只显示名称、圆点、当前颜色和箭头。
- 展开“画布背景”后色板出现，选择“暖白”后收起再展开仍为“暖白”；恢复“纸白”成功。
- 展开“笔记背景”选择“薄荷”，强制停止并重启后仍显示“薄荷”，笔记预览同步变绿；恢复“暖黄”成功。
- 新增 `DropdownChevron` Canvas 组件，替换 `CollapsibleColorSetting`、`SettingsDropdown` 和自定义字体行中的文字字符“⌄”；箭头固定放在 20dp 容器内垂直居中，三处入口使用同一组件，避免字体基线导致箭头下移或左右不齐。
- 关闭按钮固定在顶栏，滚动到“阴影样式”等行时不再与分段控件重叠。
- 外观页、储存页可正常打开；外观页“显示语言”、储存页“备份与恢复”内容正常。
- 447 项 JVM 测试通过，0 失败。
- Release APK：3,456,827 字节，SHA-256 `4F944081D079DD132D425118F283DAA8056A9A53DB0E4CC7157886AD99DC8EC1`。

### 6.4 未验证 / 待确认

- 窄窗口与分屏下的单栏设置布局未在 360dp 窗口实机复测；现有 `BoxWithConstraints` 分支未改。
- 官方“指定主题”（Specified）需要页面级主题快照，当前只有工作区级“浅/深/自动”，未实现，不添加到下拉中伪装。
- 官方图形/连线/思维导图的完整默认值仍需新增配置字段或页面格式字段，本轮只完成配色收纳与分组/组件整改。
- 官方 AI、滚动缩放、定价/成员/集成/嵌入/属性等仍按产品范围不实现。
