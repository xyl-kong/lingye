# 导出二级浮窗卡顿修复（2026-11-03）

用户反馈：点击顶栏 ⋮ 菜单中的 Export 后，界面出现明显卡顿，菜单先向左移动、再回到原位，最后二级浮窗才出现。

## 1. 原因

原实现把一级菜单和 Export 二级菜单放在同一个 `DropdownMenu` 中，并通过宽度切换控制：

- 一级菜单宽度 `264.dp`；打开二级菜单后整个 `DropdownMenu` 改为 `520.dp`。
- 二级面板通过 `Spacer(Modifier.height(exportTopDp))` 定位到 Export 行。
- 二级面板比一级菜单更靠下，弹出后整个弹窗的高度也会增加。

因此点击 Export 时，弹窗窗口需要在同一帧同时改变宽度和高度。Compose / Android 的弹出窗口在尺寸变化时会重新测量并重新定位，二级面板和一级菜单随窗口边界逐帧移动；把动画时长放大 10 倍后可清楚看到：一级菜单保持右侧位置之前会先被推向右侧/左侧，二级面板从偏右位置向左滑动，最后才稳定。普通速度下表现为一次明显的卡顿和“先移开再回位”。

## 2. 修复

- 一级 `DropdownMenu` 宽度固定为 `264.dp`，不再随二级菜单改变；Export 二级面板完全移出一级弹窗。
- 二级面板改为独立的非焦点 `Popup`：
  - 在菜单内容中记录一级菜单表面和 Export 行在弹窗内的局部坐标。
  - 点击 Export 时，用 `LocalView.getLocationOnScreen` 取得弹窗窗口在屏幕上的原点，加上局部坐标，得到一级菜单左上角的屏幕坐标。
  - `ExportSubmenuPositionProvider` 把二级面板放在一级菜单左侧 8dp、与 Export 行顶部对齐的位置，并限制在窗口内。
  - 二级 Popup 不参与焦点、返回键和外部点击处理；这些仍由一级 `DropdownMenu` 负责，关闭时同步清空 `exportSubmenu`。
- 导出项抽成 `ExportSubmenuPanel`，四个动作（HTML、Markdown、复制 Markdown、Snapshot）行为不变。
- 二级面板没有入场动画；点击 Export 后在一帧内出现在最终位置，不再随一级弹窗尺寸变化移动。

## 4. 限制

- 二级面板定位依赖弹窗窗口的屏幕原点；当前应用在 Android 15 平板上为边到边布局，验证通过。若未来改为非边到边窗口，需要减去系统栏偏移。
- 窄分屏下若左侧空间不足，二级面板会钳制到 x=0，可能与一级菜单重叠；平板全屏与常见分屏宽度下未出现。
- 二级面板弹出没有动画；若需要动画，应只对面板自身做淡入/位移，不能改变一级弹窗尺寸。
