# 选中对象任意缩放（2026-11-03）

用户反馈：选中文本框后，四角手柄只能等比缩放，需要任意改变宽高。

## 1. 原因

原实现 `Page.resizeSelectionsAnchored` 只接受一个标量 `factor`；拖拽时用指针到对角锚点的**距离比**计算该系数：

```
factor = currentDistance / previousDistance
```

因此宽、高始终乘同一个系数，只能等比缩放。文本框、图片、形状和组合选区都走这一条路径。

## 2. 修复

新增与等比缩放并存的任意缩放：

- 抓住任一角手柄时，记录选区初始几何 `FreeResizeSnapshot`（形状、图片、笔迹的起始位置与尺寸）、对角锚点和手柄抓取偏移。
- 拖动时分别计算：
  - 水平系数 `fx = |指针x - 锚点x| / 初始宽度`
  - 垂直系数 `fy = |指针y - 锚点y| / 初始高度`
- 对每个对象分别应用：`x` 与 `width` 乘 `fx`，`y` 与 `height` 乘 `fy`；笔迹逐点缩放。
- 对角锚点保持不动；选区整体最小 24 世界单位；拖过锚点时钳制在原方向，不翻转。
- 每次拖拽都从初始快照重算，避免累计误差。
- 组合选区中的每个对象按同一 `fx/fy` 缩放，相对位置保持；小对象不会被单独放大到 24。
- 文本框只改宽高，文字字号不变，文字按新宽度重新排版。

## 5. 限制

1. 目前只有四角手柄，没有四边中点手柄；任意宽高需拖角。
2. 没有按住 Shift 保持等比的反向开关；原等比 API 仍保留给其他调用。
3. 文本框缩放不改变字号，只改变排版区域。
4. 组合选区整体最小 24；内部小对象可缩到 1 世界单位。
5. 旋转后的图片仍按未旋转轴向外框缩放，与现有图片几何模型一致。
