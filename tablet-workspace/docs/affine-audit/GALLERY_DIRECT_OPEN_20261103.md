# 内容按钮直接打开模板画廊（2026-11-03）

用户要求：把图 1 的二级内容菜单直接换成图 2 的模板画廊，不再先点一次分类再进三级弹窗。

## 1. 改动

- 白板底部“内容与数据”按钮现在一次点击直接打开 `TemplateGalleryPopup`：
  - 顶部搜索框；
  - 横向分类标签（Arrows、Cheeky Piggies、Contorted Stickers、Paper、Brainstorming）；
  - 三列模板网格；
  - 点击外部或返回关闭。
- 删除原来的 `ContextualMenuHost` 二级菜单及 `cardMenu` 状态，不再需要“先选分类再进画廊”。
- 保留原功能：
  - 搜索框右侧新增图片、数据库两个 32dp 图标按钮，沿用原 `AppIcon.IMAGE` / `AppIcon.DATABASE` 图标；点击图片打开系统图片选择器，点击数据库调用 `page.addDatabase`。
  - 画廊末尾 `Cards` 标签保留原笔记/待办/项目/会议/灵感卡片预设。
  - 若当前页或工作区有模板，画廊末尾显示 `Workspace` 标签，列出工作区模板、旧页面模板和管理工作区模板入口。
- 画廊关闭、切换工具或返回时同步清空 `templateGalleryOpen`；画布快捷键的 overlay 判断也改为使用该状态。

## 2. 验证

- `dg-2.png`：点击图片图标，画廊关闭并打开系统图片选择器（MediaProvider），返回取消。
- `dg-3.png`：点击数据库图标，画廊关闭并添加数据库；随后撤销，页面恢复为 1,838 字节。

## 4. 限制

1. 图片/数据库两个图标位于搜索框右侧，是原功能的保留入口，与图 2 的纯搜索栏略有差异。
2. Workspace 标签仅在存在工作区/旧页面模板时出现。
3. 模板仍以图片对象插入，不是可编辑矢量/画布模板。
4. 只接入图 2 可见的 5 个官方分类；Arrows 仅 18/185；插入位置固定为 (400,140)。
