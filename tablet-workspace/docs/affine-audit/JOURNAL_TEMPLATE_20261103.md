# Journal 与模板页（2026-11-03）

用户截图指出“信息 → 工作区属性”中的 Journal、模板两个复选框没有实际作用，要求核对 AFFiNE 官方语义并补齐。

## 1. 官方审计

在 AFFiNE 网页版（Demo Workspace）展开页面 Info → 6 more properties，实际存在 `data-info-id="journal"` 与 `data-info-id="template"` 两行：

- **Journal**：不是普通布尔值，而是页面关联的日期。
  - 未设置时显示空复选框；勾选后设为今天（如 `Nov 3, 2026`），页面立即进入 Journals 视图。
  - 设置后该行显示日期值；页面出现在对应日期的 Journals 列表。
  - Journals 侧栏显示周日到周六的周历、Today 按钮和上一周/下一周切换。
  - 模板侧栏也会用这个日期作为页面名称（示例中“Getting Started”变为 `Nov 3, 2026`）。
- **模板**：页面级布尔属性。
  - 勾选后页面出现在侧栏 Template 列表中，列表还提供 “Create new template”。
  - 开启模板不会把页面从 All docs 隐藏。
  - Journal 与模板可同时开启；两者互相独立。

## 5. 限制

1. Journal 日期与模板标记存放在 `SharedPreferences("page_metadata")`，不在页面格式 25 内，当前备份 ZIP 不包含这两个标记；恢复备份后需要重新设置。
2. Journals 只有周日到周六的周历，没有官方的月历/年度视图；同一天允许存在多个页面。
3. 勾选 Journal 只关联当前页面并跳到 Journals，不会自动生成默认日志模板内容。
4. 模板“使用”是复制页面，不是官方的模板实例/引用；复制后修改不会影响模板。
5. 模板列表未提供重命名、删除或分类；需打开页面后在 Info 中取消模板标记。
6. 模板列表的修改时间使用月/日，没有完整时间。
