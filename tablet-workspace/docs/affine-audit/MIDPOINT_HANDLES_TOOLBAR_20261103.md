# 边中点手柄与移动时工具条收起（2026-11-03）

## 1. 需求

1. 文本/对象选中框缺少四条边的中点手柄，需要补上。
2. 选中矩形移动时，一级对象工具条消失后应在停止移动时重新出现；同一逻辑适用于无界画布所有可框选、移动的组件。

## 2. 实现

### 2.1 四条边中点手柄

- `selectionFrame` 在四角手柄之外绘制四条边的中点手柄：
  - 上/下边中点、左/右边中点；
  - 白色填充、主题色描边，直径 5.5dp（角柄 6dp，略小以区分）；
  - 文本、卡片、形状、图片、笔迹、连线、Frame、多选外框共用同一绘制。
- 命中检测新增四条边中点：
  - 左/右边中点：只改变宽度，`axis = "x"`；
  - 上/下边中点：只改变高度，`axis = "y"`；
  - 四角：宽高同时改变。
- `Page.applyFreeResize` 增加 `axis` 参数：
  - `axis = "x"` 时 `fy = 1`，只应用水平系数；
  - `axis = "y"` 时 `fx = 1`，只应用垂直系数；
  - `axis = null` 时保持原有的自由宽高缩放。
- 抓取偏移按手柄类型计算：角柄对应拖动角，边中点对应所在边的中点，避免拖动开始瞬间跳变。
- 对角/对边锚点固定，选区最小 24 世界单位，拖过锚点钳制在原方向。

### 2.2 移动时工具条收起

- 所有选中对象的一级工具条可见条件统一增加 `!dragging`：
  - 卡片、形状、文本、链接文档、思维导图节点、Frame、图片、笔迹、连线；
  - 拖动开始时工具条淡出，`onDragEnd`/`onDragCancel` 把 `dragging` 置回 false，工具条在新位置淡入。
- 移动、缩放、端点拖动都使用同一 `dragging` 状态，因此缩放时也会暂时收起工具条，松手恢复。

## 5. 限制

1. 边中点只做单轴缩放，四角仍为双轴自由缩放；没有旋转手柄。
2. 工具条使用统一 `dragging` 状态，移动和缩放都会收起；如果未来加入惯性滚动/长按拖动，需要单独区分。
3. 多选时仍是整体外框的四个角/四个边中点，内部对象不显示独立手柄。
4. 菱形、三角形等自由形状目前没有专属对象工具条（`selectedShapeIndex` 只覆盖 rect/roundRect/ellipse），本次只补了选中框手柄；这是既有行为，未在本次改动。
