# 页面行 ⋯ 菜单补齐（2026-11-02）

用户要求：检查页面行右侧 ⋯ 浮窗中尚未构建的选中项，并补齐功能。

## 2. 实现

### 2.1 添加链接文档

- 菜单项打开 `添加链接文档` 模态选择器，列出所有未删除且不是当前页的页面；每行显示页面图标、标题和标签。
- 选择目标后调用 `PageLinks.addLinkedDoc`，在当前页画布 (220,180) 处插入链接卡片；同一页多个链接按 32 世界单位错开，最多错开 5 档。
- 保存来源页、切换到来源页白板模式并选中，链接卡片立即显示。
- 选择器打开时同步关闭页面行菜单，避免菜单残留在弹窗背后。

### 2.2 复制

- 新增 `duplicatePage(source)`：调用 `Page.duplicate`，标题追加“副本”，生成新页面 ID，写入页面存储并加入 `pages`。
- 复制完成后直接打开副本，源页面保持不变；画布对象、文档块、链接卡片、图标、标签、文件夹归属由 `Page.duplicate` 一并复制。

### 2.3 在新标签页打开

- 新增应用内标签列表 `openTabs` 与 `PageTabStrip`：
  - 顶部横向可滚动标签栏，当前页高亮，右侧 `×` 关闭标签。
  - 关闭当前标签时选择列表中最后一个仍然有效的标签；没有可用标签时回到“全部文档”。
  - 关闭后台标签不改变当前页。
- 当前页在标签栏非空时会自动加入标签列表；页面被移入回收站或删除后，对应标签自动移除。
- 标签栏只在文档/白板编辑区显示，概览、设置、全部文档页不显示。
- 标签栏使用 `statusBarsPadding()`，避免与系统状态栏重叠导致顶部标签点不到。

## 3. 交互修复

1. **标签栏被状态栏遮挡**：首次实现把标签栏放在内容列最顶部，Android 15 边到边布局下标签文字与系统时间重叠，状态栏区域内的点击被系统拦截。加入 `statusBarsPadding()` 后标签栏完整位于状态栏下方，点击切换正常。
2. **选择器背后残留页面菜单**：打开“添加链接文档”时只设置 `linkedDocSourceId`，页面行菜单的展开状态没有清除。两处 `onAddLinkedDoc` 回调现在先执行 `pageActionsMenu = null`。

## 5. 限制

- 标签列表只保存在当前进程内，强停或重启应用后清空；页面内容本身已保存。
- 复制标题固定追加“副本”，没有“副本 2”去重逻辑。
- 链接文档选择器为全量列表，暂未加入搜索或文件夹筛选。
- 标签不支持拖动排序、固定或右键菜单。
- “在新标签页打开”是应用内标签，不是 Android 多窗口/多任务标签。
