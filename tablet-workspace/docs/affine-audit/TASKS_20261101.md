# 灵页任务与目标审计（2026-11-01）

## 0. 审计结论

- 当前基线：v0.15，页面格式 **25**；模拟器上有 201 个 `.page` 文件（192 个活动文档，含 `ToolbarTest` 测试页；其余为回收站中的测试页与副本），20 个历史文件；最新发布为 `lingye-v0.15-architecture-batch12-release-20261103.apk`；JVM 测试 **374 项，0 失败**。
- 项目目标仍是：离线优先的 Android 平板文档/白板工作区，逐步对齐 AFFiNE 的对象、工具栏、富文本和数据可靠性；不以“按钮存在/构建成功”代替验收。
- 审计发现的三类问题：
  1. **文档漂移**：`AGENTS.md` 仍写“页面格式 22”，`WORK_CHECKLIST.md` B 节仍列页面图标/双向链接/深色主题等已实现项为未完成；`FEATURE_MATRIX.csv` 中 92 个 `PARTIAL`、35 个 `MISSING`、5 个 `UNVERIFIED`，部分是证据缺口而非功能缺失。
  2. **P0 数据/性能证据不足**：格式迁移已有 195 页设备迁移，但缺少逐版本 fixture 矩阵；保存/启动主线程、10 MB 级数据、100/1000 对象压力尚无基准。
  3. **D2 后的真实缺口**：Note 仍是扁平 `title/body`，没有块容器/子块，也没有图片或行内格式字段；“插入到文档”已保真到 block 类型和勾选状态，但不能保真图片/行内格式。
- 本轮先执行 **T01 历史格式迁移矩阵**：从三份历史备份确认设备出现过 v4、v5、v6、v8、v11–v16、v22–v24 共 13 个版本；用合成最小页面生成器覆盖，新增 4 项测试；全部通过。**没有改页面格式，没有改用户数据，也没有把用户页面放进测试资源。**
- 本轮同时执行 **T11 文档漂移修正**，见本文件末尾。

## 3. 本轮执行记录

### T01 历史格式迁移矩阵

- 来源：三份历史备份确认设备实际出现过 v4–v24 的混合页面。**为不把用户页面内容写入源码**，测试资源不保存真实页面；新增 `LegacyPageFixtures` 生成每个版本的最小页面（固定标题、一个段落、一个圆角矩形），真实 195 页迁移另有设备证据。
- 覆盖版本：v4、v5、v6、v8、v11、v12、v13、v14、v15、v16、v22、v23、v24。
- 新增 `PageMigrationMatrixTest`：
  1. 13 个历史版本解码 → 默认字体字段 → 编码为 v25 → 再解码，比较 id/标题/块/形状/连线/图片/笔迹/文件夹/Tags。
  2. 未来格式 v26 被拒绝。
  3. 截断页面被拒绝。
  4. 损坏的 v25 尾部被拒绝。
- 结果：`288 tests, 0 failures, 0 errors`。版本清单与生成器说明见 `evidence/format-migration-matrix-20261101.txt`。
- 限制：fixture 覆盖的是设备实际出现过的版本，不是合成 1–25 全链；仍无“新版本降级导出”。REL-009 保持 PARTIAL，但迁移证据从单 v24 扩展到 13 个版本。真实历史页面只用于审计时验证，未进入测试资源或文档正文。

### T03/T04 性能基线

- 新增 `BenchmarkFixtureWriterTest`：生成 1000 shapes（175,118 B）和 1000 blocks（95,010 B）两个测试页面，不在 APK 内、不含用户内容。
- 冷启动：197 页中位数 1,177 ms；加入两个大页（199 页）中位数 1,188 ms。
- 1000 shapes 平移/缩放：50th 81 ms、95th 113 ms；普通画布同操作为 48/73 ms。
- 1000 blocks 文档滚动：20 帧全部 jank，50/95/99 均 150 ms；确认当前 `Column + verticalScroll` 未虚拟化。
- 结论与复现见 `PERFORMANCE_BASELINE_20261101.md`；优化拆分到 T03a/T04a/T04b。
