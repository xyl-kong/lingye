# CV-048 白板文本选区格式刷（2026-11-22）

## 交互范围

在白板文本框的编辑态选中一段文字，悬浮选区栏中的格式刷按钮复制选区**起始字符**的行内视觉样式。按钮显示选中态；随后选择同一文本框或另一文本框中的目标文字，样式应用一次并自动退出。再次点击源选区上的按钮可取消。操作有简短提示。

复制的样式为粗体、斜体、下划线、删除线、行内代码、前景色和背景色。目标选区原有的这些样式会被替换，范围外文字保持不变。链接、评论、公式标记及其独立元数据保持原样。文本框级字号、字体、对齐和基础颜色不参与选区格式刷，因为当前页面格式把这些属性保存在整个对象上；对局部选区写入会意外改变范围外文字。

## 实现边界

`TextFormatPainter` 只处理当前 `TextSpan` 的视觉位，不增加页面字段或依赖。一次性样式快照留在 `CanvasEditorState` 的内存状态中，不持久化；目标文本的实际样式仍走原有页面保存和历史入口。文本选区浮栏复用既有按钮、图标绘制、主题色和悬浮定位。
