# UI 设计迭代史（2026-10-28 – 2026-11-04）

灵页的界面不是一次设计完成的。绝大多数 UI 都经历了“对照 AFFiNE 官方截图/源码 → 实现 → 模拟器截图 → 用户反馈 → 再调整”的多轮修改。本文按区域记录这些轮次，便于理解当前界面为什么是现在这样，也避免后续把已否决的方案重新引入。

## 1. 设计基准与方法

- 基准：AFFiNE / BlockSuite 的公开源码、官网截图与用户提供的界面截图；能核对源码时以源码为准，不能核对时明确标为近似。
- 尺寸：以平板 2560×1600、density 320（1280×800dp）为主，另测 360dp、540dp、640dp、200% 系统字体与真实分屏。
- 证据：每轮修改后用 `adb screencap` + `adb pull` 保存截图，并在审计文档中记录文件名；关键界面放大核对。
- 原则：先保证可读性、点击区域与信息层级，再追求“像官方”；不为了视觉一致而隐藏不可用功能，未实现项用禁用态或 `PARTIAL` 标注。

## 5. 文本与对象工具条

- 文本对象：块级工具条按官方顺序（Display in Page、Note Style、Size、Scale、连接线、锁定、更多）；编辑并选中文字时切换为文本选区工具条（文本样式、对齐、粗体/斜体/下划线、更多）。
- 卡片/笔记：原位编辑、插入文档、保存模板、复制、颜色、图层、锁定、删除；待办卡增加“勾选下一项”。
- 图形：矩形/圆角矩形/圆形切换、填充/边框色、实线/虚线/无边框、粗细、复制、图层、锁定、删除。
- 连线：端点圆点/箭头/无、直线/曲线、光点颜色动效、文字标签、翻转方向。
- 选中框：四角手柄 + 四边中点；边中点只改单轴，角柄自由缩放；拖动时工具条隐藏，松手恢复。
- 相邻“＋”：文本与卡片选中后左右出现“＋”，点击复制相邻空对象并进入编辑；拖动隐藏、边缘隐藏该侧。
- 内联编辑：从“完成”按钮改为点击外部、`Esc`、`Ctrl+Enter` 退出；编辑中隐藏选中框与手柄；文本框编辑层去掉阴影。

反复点：文本工具条经历“块级/选区”两套状态多次调整；Scale/Size 菜单重排；卡片与文本的“＋”先做文本后扩展到卡片；内联编辑的退出方式改了两次（按钮 → 无按钮）。

## 6. 设置弹窗（修改轮次最多）

按 `SETTINGS_IMPROVEMENTS.md`，设置至少经历 11 轮：

1. 整页设置改为 AFFiNE 风格模态弹窗（工作区卡、分类导航、关闭按钮）。
2. 按官方截图重做左浅灰导航 + 右白色内容；导航收敛为外观/编辑器/键盘快捷键/关于灵页 + 偏好设置/储存。
3. 编辑器与快捷键板块补齐（字号范围、日期格式、代码行号、快捷键分组）。
4. 视觉重设计：主题状态块、白卡色点取色器、日期内联芯片、右栏留白、代码行号对齐、文案缩短并移入帮助。
5. 全局色圈、自定义色卡、RGB/HSV 取色器、笔记背景/圆角/阴影/边框与预览、按钮缩放。
6. 紧凑控件与笔记预览：开关 38×22dp、滑块 26dp、分段白胶囊 + 黑色选中块。
7. 极窄窗口：内容宽度 <520dp 时单栏（分类列表 → 详情 + 返回），系统返回先回列表。
8. 分段切换滑动动画：黑框 220ms 平滑移动，文字随覆盖变色。
9. 深色主题：三档主题、深色令牌、系统栏图标同步。
10. 应用级与文档编辑快捷键页、页面图标、双向链接、单笔记阴影/圆角。
11. 设置弹窗收紧、开关重设计、帮助浮窗统一。

反复点：设置从整页 → 弹窗 → 官方布局 → 视觉重做 → 紧凑化 → 深色，至少 6 次大改；主题控件先三段（含禁用）后改为三档可用；语言从分段改下拉；取色器从胶囊 → 白卡色点 → HSV/华为风格白板，改了 3 次。

## 7. 颜色与取色器

1. 初版颜色胶囊/色点。
2. 经典十色色圈 + 自定义色卡（最多 12）+ RGB/HSV 折叠取色器。
3. 取色器改为白卡 + 14dp 色点 + 深色标签，修复墨黑/深灰标签不可读。
4. 颜色序列支持直接取色（自定义序列）。
5. 华为风格白色取色板：白色面板、色相条、明度/饱和度区与吸管。
6. 设置与画布所有颜色入口统一接入同一套取色器。

反复点：取色器交互与视觉被重做 3–4 次；“墨黑/深灰不可读”是实际截图发现后才修的。

## 8. 模板、图标与画廊

- 模板：早期只有 5 个卡片预设；后按 AFFiNE 官网分类下载 68 张官方 PNG，做搜索 + 5 个分类 + 三列网格；再次改为“内容按钮一次点击直达画廊”，删除二级菜单；保留 Cards 标签。
- 图标：`@blocksuite/icons` 路径统一线型图标；工具栏插画先出三方向稿，选方向 A 后重绘 6 个 VectorDrawable；文件夹使用官方 Lottie；页面图标支持 emoji；帮助“?”改为 `HelpGlyph` 几何居中。
- 画廊：官方模板以图片对象插入，不是可编辑矢量；仅接入官网图 2 的 5 类，Arrows 18/185；插入位置固定；这些限制在界面与文档中标注。

## 9. 菜单与通用组件

- 第一轮：各菜单手写 `DropdownMenuItem`，图标 19dp/17dp 混用、禁用色不一致。
- 第二轮：抽 `layerMenuEntries`、`MenuSectionLabel`、`MenuCheckItem`，统一画布图层菜单。
- 第三轮：新增通用 `MenuRow`（18dp 图标/自定义前导、尾部提示、禁用/危险/勾选态），迁移块菜单、块类型、页面行菜单。
- 第四轮：`MenuRow` 增加副标题，迁移侧栏导出/新建/页面/回收站/文件夹菜单、首页排序/新建/移动文件夹、块插入、文档属性、设置选项。
- 反复点：菜单迁移做了 3 批；Export 行因尾部“›”与子菜单位置计算保留原实现；禁用项颜色修过一次（禁用优先于危险态）。

## 10. 响应式、深色与动效

- 360dp：首页、文档、白板底栏、设置单栏均可用，白板底栏可横向滚动。
- 540/640dp：设置单栏/两栏切换；首页头部两行；文档块类型条 `FlowRow` 换行；真实分屏（Chrome + 灵页各 640dp）复核。
- 200% 字体：画笔/文本参数条完整，无裁切。
- 深色：所有主要界面与画布工具条、取色器、弹窗统一深色；分段选中框与开关反转。
- 动效：分段选中框 220ms 滑动；页面/工具选中轻量过渡；系统关闭动画时停止背景漂移。

## 11. 为什么 UI 会反复改

1. **基准从截图变源码**：早期按截图近似，后来核对 BlockSuite 源码才发现结构/尺寸差异，必须重排。
2. **用户逐轮反馈**：侧栏对齐、顶栏胶囊、圆角/阴影、颜色可读性、按钮位置等，很多是看到实际截图后才提出的。
3. **窄屏与字体暴露问题**：宽屏正常的设计在 640dp、360dp、200% 字体下会折行或裁切，只能二次布局。
4. **功能增加导致工具条膨胀**：每加一个对象能力就多一个按钮/菜单项，必须反复去重、分组、改二级菜单。
5. **“像官方”与“可用”冲突**：官方有些交互依赖桌面端（悬停、右键、滑出菜单），平板触控需要改成常驻工具条或长按菜单。
6. **视觉证据驱动**：每轮都截图放大核对，发现“看起来差不多”但实际 1–2dp 偏差、图标基线不齐、颜色对比不足。

## 12. 当前仍不完美 / 已知限制

- 部分界面是“近似官方”，不是逐像素还原；官方桌面端的滑出菜单、右键菜单在平板上改为常驻/长按。
- 工具栏在极窄窗口仍需横向滚动；对象工具条靠近边缘时会翻转，但复杂多选下仍可能遮挡。
- 设置页仍有未实现项（Ask 模式、快捷键自定义等），以禁用或说明呈现。
- 深色模式覆盖主要界面，但个别第三方资源（官方模板 PNG、Lottie）不随主题变色。
- 真实手写笔、压感与手掌误触未在真机验证；模拟器截图不能代表最终视觉与触感。
