- Journal 自动创建和时区边界。
- Page width 的打印/导出行为。
- Linked Doc 在目标删除、循环引用和同步模式下的行为。
- 协作冲突、离线重连和版本清理。

## 4. 不能当作事实的推断

以下只是审计推断，除非后续有实验，否则不能写为已确认：

- “Compose 默认会处理中文 IME，因此无需专项测试”。
- “存在 `AtomicFile` 就保证所有事务安全”。
- “点阵背景存在就等同于 AFFiNE 的背景能力和性能等价”。
- “形状选中工具条可显示就表示所有对象工具条完整”。
- “有 `LocalDatabase` 就实现了 AFFiNE Database”。
- “有 SharedBlock 就实现了 Synced Doc 或 CRDT 协作”。
- “导出 ZIP 就实现了 AFFiNE 的标准导入导出”。
- “README 声明桌面端设置不适用于平板”就等于用户批准将那些能力标为 `NOT_APPLICABLE`。
