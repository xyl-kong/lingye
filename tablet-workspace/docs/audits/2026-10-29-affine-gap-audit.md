# AFFiNE 对照与功能审计

审计日期：2026-10-29。对象为灵页 0.8 当前源码；AFFiNE 仅作为产品能力和风险参考，不要求复制其账号、云服务或数据格式。

## 已实现并验证

- 中文、英文界面切换；首次启动跟随设备语言，选择持久化。
- 内置卡片预设、数据库标准状态和已知错误提示随语言切换；用户内容不自动翻译。
- 白板手势取消回滚、稳定对象 ID、损坏页面隔离、备份/恢复与撤销重做已有自动测试。
- 卡片、工作区模板、轻量数据库、表格式和按状态分组看板已有基础实现。

## AFFiNE 官方能力对照

AFFiNE 官方文档强调两种页面模式、由块组合文档和画布、块引用/同步块、数据库多视图、Collections、框架与分组。灵页已有本机共享文字、图片和数据库，以及数据库表格、看板、列表和月历，但选区富文本及图文融合能力仍有限，也缺少 Collections、框架和关系索引。

官方发行记录显示 2026-10 仍持续修复桌面安装、会话保存、导入和数据库搜索等基础问题；开放 issue 中近期可见的类别包括：

- 目录/工作区结构异常与会话持久化，例如 #15554、#15613。
- 数据库成员值类型不一致导致搜索漏项，以及关联文档标题不可搜索，例如 #15746；iPad 浏览器中的数据库编辑限制见 #15710。
- Markdown 之外的导入格式仍不完整，复杂导入可能重复或丢失结构。
- Android 仍有共享工作区无限加载和自托管连接问题，例如 #15707、#15438。
- 大画布性能仍是开放需求 #14333；手形工具导致选择丢失见 #15617。
- 画布社区需求仍包含函数图、图片超链接和更完整视图。

这些结果用于确定优先级，不代表灵页需要实现 AFFiNE 的云同步、AI、MCP 或自托管能力。

## 当前缺口

### P0

1. 工作区启动加载、备份读取/解压/恢复、显示用图片解码和自动保存写盘已转到后台；自动保存编码及显式页面切换保存仍在主线程，大型页面仍可能短暂停顿。恢复过程的中断和故障注入尚需验证。
2. 中文项目路径下 Gradle 测试运行器会类加载失败；目前通过英文临时副本测试。
3. 尚无真机手写笔验收，手掌取消、压感、旋转、分屏和性能仍未确认。

### P1

1. 笔迹已加入稳定 ID、框选及移动缩放删除；选择工具增加边缘对齐和网格吸附。仍缺少居中与分布对齐、对象吸附、跨页面剪贴板和锁定。图形、图片、连线和笔迹使用统一顺序进行绘制和命中，新增图层菜单；复杂画布交互尚需回归。新增交互仍需完整模拟器回归。
2. 选择模式中的双指缩放、连线密集时的性能和可见区域裁剪未完成。
3. 关系端口还没有输入/输出语义、命名、目标高亮和完整的手势取消反馈。

### P2

1. 本机共享块支持选区及整块文字格式、图片和数据库，以及独立的持久化撤销／重做；历史最多保留 30 步并受到大小限制，不与页面撤销合并。画布卡片不是任意文档块的共享引用。
2. 选区模板支持图形、图片、笔迹和内部连线；不支持数据库字段模板、跨选区链接保留或模板图库预览。
3. 数据库已有表格、看板、列表和月历视图，支持日期字段，并持久化视图、排序字段、排序方向和日历字段；仍没有拖拽排序、关联字段或日历内直接编辑。

### P3

1. 文档不支持选区富文本、块拖拽、引用、代码、表格和斜杠菜单。
2. 文件夹支持重命名及删除并迁移页面，使用恢复日志；中断恢复和完整操作尚需测试。不能嵌套，回收站没有永久删除。
3. 搜索覆盖页面、文字块和卡片，但还没有统一的关系索引、标签、收藏和双向链接。

### P4-P5

1. 手写只有整笔橡皮，没有压感、局部橡皮和厂商设备差异测试。
2. 没有同步、版本历史、冲突处理、权限和实时协作；普通 ZIP 备份不能当作同步。

## 建议顺序

先完成 P0 的后台 I/O 和真机输入验证，再处理框选、画布性能和卡片字段，最后才评估块引用、多视图及同步。AFFiNE 的开放 issue 也说明这些基础数据与输入可靠性问题不会因增加更多功能而自动消失。
