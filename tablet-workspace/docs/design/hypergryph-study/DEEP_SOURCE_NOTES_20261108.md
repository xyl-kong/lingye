## 3. 关于“数据深入”的证据缺口

1. **已证实**：上述官方页面与官方通讯中的功能逻辑、分类结构、真实编号和开发目标；[独立 CSS 研究](https://ak-ui.yyj.moe/en/guide/official-site-study)记录《明日方舟》官网局部字体声明、新闻排布和“更多”链接 `.3s` 颜色过渡，但不是官方标准。
2. **尚不能证实**：鹰角游戏 UI 的统一设计令牌、精确色板、实机字号/网格、各组件完整状态、所有动效时长/缓动以及触控成功率。官方新闻图片是特定版本的示意，不能从一张图推出整个设计系统。
3. **产品处理**：本项目的工业主题色值、圆角、时长均标为**原创提案**，按 Android 平板实际测试定稿；不以“官方同款”宣称。下一轮若需要更严密的视觉测量，应建立同版本同设备的游戏/官网录屏样本，记录 viewport、帧率、状态、图像坐标和来源许可，再分析而非凭记忆估数。

## 4. 对主题规范的增补

- `Industrial Terminal` 增加**数据密度模式**：高密度列表用清晰列槽，空状态留白；主题不改变内容排序/筛选行为。
- 状态色外再加**来源/连接/约束标签角色**，如“已绑定”“未连接”“超上限 24/20”“共享内容”；颜色始终配文字或形状。
- 可选连线流光默认不用于普通静态线的进度表达；若仅视觉反馈，设置说明明确，并在减少动效时停用。
- 工业主题的“模块编号”仅在真实序列中出现；不把 C01–C11 研究编号直接放入产品。
