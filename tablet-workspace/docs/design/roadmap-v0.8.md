# 灵页 0.8 功能缺口与开发计划

基准：2026-10-29 对 0.8 源码、README、既有设计和 Android、AFFiNE、ComfyUI 官方文档进行核对。状态描述以当前源码为准；需真机验证的内容不视为已验收。

## P0：数据与交互可靠性

1. 手势事务：移动、缩放、擦除在手势取消时恢复操作前状态；拖动期间不将中间状态误记为最终历史，落笔/松手只生成一次撤销。分别测试系统取消、应用切后台、中断和撤销重做。
2. 对象身份与存储：选择、分组与连线使用稳定 ID 而非列表索引；分离画布数据、几何、命中和手势状态；验证删除、撤销、恢复后不会选错对象。页面格式迁移必须保留 0.6–0.8 数据并测试旧备份。
3. 存储错误隔离：当前加载全部页面时单页异常可能影响列表加载；改为逐页报告及保留原始文件，不覆盖损坏数据。备份、图片解码和恢复移出主线程，补充大文件、中断、空间不足和恢复回滚测试。
4. 完成平板实测基线：至少一台支持手写笔的安卓平板验证手掌、触控、笔压、旋转、分屏和性能；记录机型与 Android 版本。未取得真机时保留待验状态。

## P1：白板和连线体验

- 框选覆盖笔迹、曲线和图片卡片；明确包含/相交规则和组成员。提供四角整体缩放、对齐/吸附、锁定、图层和复制粘贴；空白拖动组合的行为可预期。选择模式中的双指缩放需要单独实现及测试。
- 曲线控制点按端口方向计算，处理反向、垂直、重叠和同对象连接，避免穿过卡片；支持直线、曲线、折线、箭头、标签及选中后的样式修改。保持绘制、命中、光点采样共用几何数据。
- 卡片端口区分输入、输出和关系，允许命名；拖动时高亮目标、扩大触控范围并支持手势取消；连接建立后可改绑与解绑。端口只是关系标识，不默认执行数据流。
- 光点：保留单线和总开关；按路径长度限制速度，增加淡入淡出与轻微尾迹；后台、不可见区域及系统减少动画时暂停。测试曲线变化、密集连线、帧率、耗电和浅深色对比。
- 画布可视化：缩略图、适配内容、快速定位、画布缩放百分比、网格及上下文工具栏；在大画布中只处理可见对象并测量性能。

验收：模拟器覆盖绑定、改绑、解绑、移动、缩放、框选及撤销；典型 100/1000 对象场景采集帧率与内存，具体性能门槛先测基线再制定。

## P2：卡片与模板

- 可编辑卡片：实现真正的待办勾选、图片卡、长文自动换行与高度适配，支持颜色、文本、尺寸和内容顺序；现有待办的符号是纯文本。
- 卡片字段：支持文本、多行、复选、图片、标签的添加、重命名、排序与删除；明确字段删除对实例的影响，未知字段必须安全保留。
- 模板库：用户模板从页面迁移为工作区级，提供创建、修改、重命名、复制、删除和搜索；模板更新不改已有实例，删除不删除实例。内置模板保留独立副本语义。
- 布局模板：将卡片、相对位置、内部连线与素材保存成模板，插入时生成新 ID 并重映射内部引用；外部连接不复制。支持模板导入导出和备份恢复，涉及图片时包含素材。
- ComfyUI 借鉴：卡片分类、端口提示、折叠、组合及可复用布局；执行型节点/运行工作流是独立后续项目，需要单独设计，不暗示已具备 AI 能力。

验收：修改模板与实例互不影响；多个页面可访问用户模板；模板与图片备份恢复后可再次插入；重名、删除、未知类型和旧页面迁移均有测试。

## P3：文档与知识组织

- 支持选区富文本、拖动块排序、列表/引用/代码/表格和斜杠菜单；同一内容在文档及画布中以共享块呈现，而不是互相复制的文本。
- 目录与知识：嵌套文件夹及重命名、删除；收藏、标签、文档链接、双向链接、全局搜索覆盖卡片；回收站提供永久删除并明确确认。
- 数据库先做轻量表格和看板，包括字段、过滤、排序与多视图；之后再评估日历等视图。
- Markdown、图片、PDF 等常见格式的导入导出按数据保真程度逐步实现；明确哪些样式或空间布局不能无损转换。

## P4：手写与安卓适配

- 系统手掌取消事件处理、可配置手写笔/手指职责、压感及历史采样、低延迟绘制；支持整笔和局部橡皮。Android 版本和不同厂商设备行为需分开验证。
- 适配横竖屏、分屏、键盘/鼠标、外接显示器和动态窗口尺寸；保证端口触控尺寸与可访问性，设置减少动效。

## P5：同步与协作

- 先定义本地优先存储、版本历史、冲突处理及备份策略，再选择同步协议；模拟离线编辑、断网恢复、冲突和数据迁移。
- 多端同步、分享、权限和实时协作属于独立工程，不将普通备份当作同步。AI 能力应另行定义服务、隐私、成本及离线降级。
