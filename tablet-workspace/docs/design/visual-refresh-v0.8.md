# 灵页视觉升级

日期：2026-10-29。目标是提升平板触控工作区的辨识度和灵动感，同时保持离线、文档与画布融合的产品方向。

## 视觉语言

- 紫蓝为主色，薄荷绿表示保存和显示状态，珊瑚红表示删除等破坏性操作。
- 侧栏和主编辑区作为两个悬浮圆角面板，置于浅色柔光渐变背景上。
- 标题使用较高字重，辅助文字使用灰色层级，减少传统表单式界面感。
- 页面、模式、工具和数据库视图使用统一的细线图标；图标由 Compose 原生绘制，不依赖位图或外部图标字体。
- 语言切换收纳在左侧底部的独立设置页；顶部撤销、重做、移动和删除等常用操作只显示图标，避免中英文长度变化导致工具栏跳动。
- 模式按钮、数据库视图和主要操作使用固定宽度或等高权重布局，文字限制为单行省略。

## 动效

- 背景柔光以约 22 秒周期缓慢漂移，避免高频闪烁和干扰阅读。
- 侧栏展开、收起使用淡入与横向滑入。
- 文档/白板模式、页面列表、工具选中和保存状态使用 160–260 ms 的颜色或透明度过渡。
- 工具选中增加轻微弹簧缩放；系统动画缩放为 0 时停止环境漂移。
- 动效只表达状态变化，不阻塞画布手势，也不替代系统“减少动画”设置。

## 白板网格

- 圆点网格使用世界坐标间距，在平移和缩放时与内容一起移动。
- 缩放过度密集时自动隐藏点阵，圆点尺寸在屏幕空间受上下限约束。
- 颜色保持低对比度，优先突出笔迹、图形、文字和连线光点。

## 工作区概览

- “概览”作为文档和白板之外的工作区视图，沿用 AFFiNE 个人中心的宽松留白与分栏层级，但内容改为本地知识库指标。
- 首屏展示页面、内容字符、画布对象和本地存储；其中数据库编码、图片引用和页面编码分别计算，避免把内部格式误当成用户内容。
- 编辑热力图基于应用私有页面文件的修改日期，显示最近 365 天的活跃日；不使用虚构的云服务调用记录。
- 下方提供资料状态和最近页面，可直接返回对应文档。

## 连接线与卡片选中

- 连接线参考 ComfyUI 的端口与关系语言：左侧输入为薄荷色，右侧输出为紫色，顶部和底部为关系端口；拖线时最近目标端口出现高亮光圈。
- 曲线使用端口方向控制点，绘制白色隔离描边和选中光晕；端点默认使用圆点，可在圆点、箭头和无端点三种样式间切换。
- 卡片与其他图形采用四角圆形手柄，任一角均以对角为锚点等比例缩放。
- 卡片选中时在对象上方显示类似 AFFiNE 的悬浮工具条，提供编辑、模板、缩放比例、颜色和删除入口。
- 卡片、图形和图片可复制为带新 ID 的独立对象，复制操作进入现有撤销历史。

## 验证

- 中文和英文长文案在 Pixel Tablet 横屏下保持可读，工具栏可横向滚动。
- 文档、白板、页面列表、数据库表格/看板、备份/恢复和画布工具均带辨识图标。
- 单元测试覆盖网格偏移数学、双语状态和原有数据行为；界面通过模拟器截图验收。
