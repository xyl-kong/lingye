# 灵页白板与卡片系统设计草案

基准：灵页 0.6 源码及 README；2026-10-29 查阅 AFFiNE 和 ComfyUI 官方文档。本文为设计，功能尚未实现。

## 产品方向
以离线优先的平板笔记和可视化组织为核心；采用 AFFiNE 的文档与画布融合、ComfyUI 的可发现节点和可复用组合的思路。第一阶段的连线表达关联，不代表可以执行 ComfyUI 工作流或运行 AI。

## 连线与端口
- 借鉴 ComfyUI 的可见输入/输出插槽：卡片默认左侧输入、右侧输出，端口沿卡片边缘排列并可命名；图形默认提供上下左右四个关联端口。端口与卡片/图形的视觉语言统一：小圆点、细描边、柔和主题色；未选中时低对比度，选中、拖线及靠近时清晰显示并高亮候选端口。
- 端口视觉直径约 8 dp，实际触控命中区至少 48 dp；放大缩小时维持屏幕可触控尺寸。触摸端口拖至目标端口创建连接；选择既有连线后拖两端手柄可重新绑定，放在空白处变为自由端；取消手势恢复原状。端口默认允许多个关系连接，第一阶段不做数据类型校验或节点执行。
- 连线默认使用平滑曲线，方向从起点指向终点；同时保留直线、折线作为后续选项。线条 2 dp 左右，颜色与对象协调，选中时提高对比但不大幅变粗。图形支持中心锚点作为可选项；旧版中心绑定保留显示语义，用户可手动改绑端口，避免升级后布局突变。
- 对象删除时，在最后可见位置解除相应端的绑定并保留线；对象移动、缩放、组合变换和撤销恢复时，线与端口同步更新。重叠对象、同对象连接和零长度需要稳定回退。

## 连线光点动效
- 每条线可开启或关闭“流动光点”，页面还有总开关；新建连线默认关闭以避免画布密集时干扰。总开关关闭仅暂停显示，不覆盖每条线原有设置，重新开启后恢复。设置随页面及备份保存。
- 默认单个光点沿实际曲线路径按弧长从起点匀速向终点前进，抵达后柔和淡出，再从起点淡入；约 2.8 秒走完中等长度连线，并将速度限制在约 40–120 dp/秒以兼顾长短线。颜色取连线色的明亮变体，核心约 3 dp，轻微光晕约 7 dp、低透明度；尾迹短而柔和，不闪烁、不改变底线宽度。缩放时大小在屏幕空间保持可读且不过度耀眼。
- 方向明确的连接才展示方向性流动；无方向关系线可在启用动效时按创建起点至终点展示，界面说明光点仅为视觉提示，不代表数据正在运行。线被重新绑定或变形时重新采样路径，避免跳离线条；极短线不显示移动光点。
- 使用一个共享动画时钟，仅绘制屏幕可见、开启动效的连线；页面不可见或应用进入后台时暂停。启用系统减少动画时停用流动并保留静态线。大量连线时优先保持交互流畅，允许自动降低刷新频率并明确验证。
- 验收：浅色/深色背景及不同颜色下仍可辨识；同时显示多条线时不会明显闪烁、刺眼或遮挡文本；平移缩放、端点拖动、重启恢复及全局/单线开关均正常。参数是首版视觉基线，应在模拟器和真实平板上观察后调整。
## 框选与组合缩放
- 选择工具中从空白区域拖出框；从左向右仅选择完全包含的对象，从右向左选择相交对象。选择结果的轮廓与数量实时显示；轻点空白清除，使用多选开关增减选区。两指始终平移/缩放画布，避免与单指框选冲突；手写工具保持原防误触规则。
- 组及多选显示统一包围框和四角手柄；拖角以对角为锚点等比例缩放，图片保持比例；支持最小尺寸，避免翻转和负尺寸。拖动框内空白或成员移动整体；普通点击组内对象选中整组，进入组编辑后可选单项。
- 框选覆盖图形、图片、卡片和笔迹；连线按线段与选框关系处理。组内连接两端随对象重新计算；自由端随选中连线一起变换；只选择组的一部分时，未选对象不移动。第一版限制一层组合，明确不支持嵌套。
- 整次拖拽作为一次撤销操作；命中手柄优先于对象与连线，屏幕像素定义最小触控范围，缩放后仍易点选。

## 卡片与模板
- 初始卡片：文本笔记、待办清单、图片说明、项目计划（目标/任务/进度）、会议记录（议题/结论/行动项）、灵感卡（标题/描述/标签）。卡片本身可编辑标题、内容、颜色、大小和顺序，可拖拽、框选、组合并连接。
- 内置模板只读，插入时创建独立副本；用户可修改实例并“保存为我的模板”。模板保存结构、默认文本、样式和可选图片；之后修改模板不会自动改写现有实例。用户模板可重命名、复制、删除、导入导出，删除模板不删除已创建卡片。
- 基于类型化字段及文档块实现卡片，初版字段为文本、多行文本、复选项、图片、标签；用户可增删改名及排序字段。删除字段先确认并明确影响，保留现有实例。未知字段类型保留原始数据并提示不支持，不静默丢弃。
- 卡片组合可存为布局模板：记录对象相对位置和内部连接，插入时重建 ID 并重映射内部连线；外部连接不复制。子图、可执行节点和自动化属于后续独立项目。

## 技术和可靠性
- 抽出画布对象统一 ID、边界、命中、变换与绘制接口，选择集合保存 ID 而非列表索引；独立管理手势状态、坐标变换、连接几何、组合和历史事务，避免继续堆积 MainActivity。
- 本地存储升级并兼容读取 0.6；保存前原子写入，损坏时保留原文件并提示。模板、素材及其引用包含在备份里，导入时校验数量和大小、重映射 ID；旧备份继续可读。
- 测试覆盖边界几何、绑定/解绑、组合缩放、框选、取消手势、撤销重做、旧数据迁移、模板复制与备份恢复；模拟器验证触控、重启持久化、缩放坐标和工具切换。真机单独验证手写笔、掌触和性能。

## 当前差距与顺序
1. 基础画布：现在只有中心绑定、逐个多选、简单组合移动；缺框选、组合缩放、端点拖拽、端口锚点、连线动效、对象图层及丰富连线。
2. 卡片与文档：现在有简单块，格式作用于整块，页面卡仅为入口；缺画布可编辑块、选区富文本、自由卡片与模板。AFFiNE 支持块引用和两种视图。
3. 组织能力：当前有搜索、单层文件夹与回收站；缺标签、收藏、嵌套文件夹、双向链接和关系索引，缺数据库和多视图。
4. 手写：已有基本画笔、整笔橡皮和仅手写笔模式；缺压感、局部擦除及真机掌触验证。
5. 数据与协作：有本地 ZIP 备份，但缺跨设备同步、协作、分享、版本历史及通用格式导入导出。
6. 产品体验：缺适合大画布的缩略图、定位、对齐吸附、快捷菜单与完整触控适配；实际大数据量性能需测量。

建议实施顺序：① 统一对象与历史事务，完成锚点、框选、组合缩放；② 卡片基础与预设模板；③ 用户模板和布局模板；④ 文档块、链接和组织；⑤ 数据库、多视图；⑥ 可靠同步及协作。每阶段分别构建并在模拟器验证，先保证数据兼容再扩展。
