## 3. 文本编辑 / IME

当前：

- 画布文本/卡片/思维节点统一 `cardEdit` 覆盖层，`BasicTextField` 标题+正文或单字段（4216-4242）；每次输入调用 `changedText` 进入页面历史（750ms 合并）。
- 内联编辑时画布快捷键返回 false（2559）；Back 退出编辑、隐藏键盘（2652-2656）。
- 页面卡编辑用 `pageCardSelected` + 60ms 延迟聚焦（2367-2371）。
- 没有 IME action（Done/Next）、没有 `imePadding`/WindowInsets 监听、没有组合文本（composition）专项处理、没有选区级格式。
- 文档块编辑另有一套 BasicTextField 与 Ctrl+B/I/U、Ctrl+Alt+1–6 快捷键（1773-1822,1928-1953）。

目标/决策：

1. 保留官方“双击进入文本编辑、Esc/Back 退出”的语义；Android 上 Back 必须先退出编辑再退出工具/页面。
2. 内联编辑覆盖层必须监听 IME Insets；输入框不得被键盘遮挡。
3. 文本选区状态是统一上下文工具栏的前置条件；阶段 D 先为 Text/Note 引入选区模型，再谈选区格式。
4. 中文/日文组合输入、删除回放、第三方 IME 需真机矩阵；模拟器 Gboard 不足以证明。
5. 不在未确认的情况下删除桌面端文本能力；缺失能力在工具栏中显式禁用/标注。

## 5. 旋转、分屏与窗口

- 当前状态恢复：页面/模式/工具/视口/选区通过 `WorkspaceSession` 保存（B：862-882；2338-2354）。
- 没有 ViewModel/SavedStateHandle；Activity 重建依赖本地会话文件。
- 横屏/竖屏/分屏的布局适配在 360dp/640dp/200% 字体有部分验证；旋转、真正分屏、折叠屏未验证（`UNVERIFIED_ITEMS.md` U-PROJ-001/005/013）。
- 沉浸式画布：`SystemBarsEffect` 隐藏/恢复系统栏（2253-2270）；键盘 Insets 未处理。
- 软键盘 + 分屏 + 工具条三者的避让没有结构化测试。

## 7. 长按与上下文菜单

- 底部工具按钮：长按 1600ms 显示名称+快捷键；悬停 320ms（`VisualDesign.kt:335-368`）。
- 文档块：长按拖拽手柄重排（1851-1886）。
- 画布对象：无长按上下文菜单；对象操作通过单击工具条。官方桌面右键菜单/长按菜单为 PRIOR/UNVERIFIED。
- 决策：平板保留“选中 → 工具条”为主路径；长按菜单可作为阶段 F 增强，需先确认官方行为，不得凭空添加。

## 11. 结论

当前 Android 交互已覆盖核心触控/手写笔/键盘路径，但触控目标偏小、IME/Insets 与选区文本是主要缺口；真实手写笔、第三方 IME、旋转/分屏仍是 UNVERIFIED。阶段 C/D 必须把“Android 适配差异”作为显式决策记录，不能把桌面端未验证能力直接删除或标为完成。
